把 S6 表 H 的识别结果**翻译成 scene.json 节点结构**:

- 命中 pattern → 套对应 pattern.md 模板生成 JSON 子树

- 不重新抽 Variant (S6 已识别)

- 不写 flow 跳转 (S9)

## 输出: 屏幕级 scene.json 骨架 (扁平, 无 INSTANCE 节点, 无 components[])

```json
{
  "screens": [
    {
      "name": "界面_主地图",
      "type": "FRAME",
      "w": 1080, "h": 2400,
      "layers": [
        // ... 屏幕顶层节点: 全是 FRAME / RECT / TEXT / component_ref 占位
        // ⚠️ 没有 INSTANCE 节点 — Claude 阶段一输出扁平 FRAME, INSTANCE 是 S11 自动抽取的
      ]
    }
  ],
  "components": []  // 阶段一为空, S11 extract_components.py 抽取后填充
}
```

> 🔴 **关键 — S7 输出"扁平 scene.json", 不是 v20.6 schema**
>
> - **没有 INSTANCE 节点** — 8 个列表行就写 8 个独立完整 FRAME (children 完整)
> - **没有 components[] 数组** — S11 自动抽取后填充
> - **没有** `component_name` / `variant` / `overrides` 字段
> - **隐藏用 `visible: false`** — S11 抽取时自动识别为"空 Variant"
> - **实例间差异直接写**: 每个扁平 FRAME 内的 TEXT.content / 图片字段直接写实际内容, S11 自动提取到 INSTANCE.overrides

## 验证 (S7 输出前必过)

1. **命名白名单合规** (7a #1): 所有节点 name 前缀都在白名单内
2. **JSON 格式 + 字段命名合规** (7a #2): RECTANGLE / content / textAlignHorizontal / layers vs children / 下划线 vs 驼峰 字段名正确
3. **fill 字段省略** (7a #3): 手搓 FRAME / RECT 都没写 fill 字段
4. **children 顺序合规** (7a #4): 底到顶, 关闭按钮放最后
5. **卡片外壳 RECT** (7a #5): 卡片/弹窗外壳是 `底板_xxx` RECT, 不是 FRAME
6. **无一层底** (7a #6): FRAME 不同时有 fill + children
7. **额外字段约束** (7a #7): TEXT 不写 w / 不写 stroke / 同组尺寸一致 / 同屏 name 唯一 / 无老命名残留
8. **按钮分组合规** (7b): 装饰都在按钮 children 内, 没有平级
9. **嵌套按钮无冲突** (7b): `按钮_xxx` FRAME children 递归无 `按钮_` 前缀
10. **进度条三层结构合规** (7c): 三层 XXX 一致, 内部不带"进度", Z 序正确, 内缩 + 中心对齐
11. **角标包装做法 B** (7c): 命中 component_ref 时, 外层包 `按钮_xxx` FRAME
12. **`component_ref` 占位写法** (7c): 独立 key + 不写 layoutSizing + w/h 已等比缩放
13. **扁平形态合规** 🔴 (7d): 没有 `type: INSTANCE` / `component_name` / `variant` / `overrides` 字段; `components[]` 是空数组 `[]`
14. **子 CCB 显隐合规 + 子节点 name 一致** (7d): 同形态父级 children 结构一致, 用 `visible: false` 表达隐藏 (**不用** `variant: "空"`); 子节点 name 100% 一致
15. **实例间差异直接写** (7d): 每个扁平 FRAME 内的 TEXT.content / 图片字段直接写实际内容
16. **浮层 / 界面背景** (7d): 浮层 `layers[0]` 有遮罩; 界面如有背景图, `layers[0]` 有全屏背景
17. **constraints 写法合规** (7e #1): 屏幕顶层 + NONE 父容器子节点写, AL 父容器不写; 角标用 LEFT/TOP + 正坐标
18. **AL 容器字段齐全** 🔴 (7e #2): `primaryAxisSizingMode: FIXED/AUTO` + `counterAxisSizingMode: FIXED/AUTO` + 对齐字段; 弹性缝隙 `layoutSizingHorizontal: FILL + w:0 h:0`
19. **滚动区字段合规** 🔴 (7e #3): `clip_content: true` (下划线) + `overflow: VERTICAL/HORIZONTAL`; 子容器 `primaryAxisSizingMode: AUTO + layoutSizingVertical: HUG`; 固定区/滚动区已分组
