# 单图标_无角标 pattern

独立的 icon 元素, **不附加在其他主体上**(不像角标), **没有边缘角标**(跟"icon+角标"的复合区分)。

## 5 维特征

| 维度 | 规律 |
|---|---|
| 形状 | **近正方形**(w ≈ h, 长宽比 0.85 ~ 1.15)|
| 构成 | 1-3 层:可能 底板 + 装饰 + 主 icon |
| 位置 | 独立元素, 不溢出他物 |
| 量级 | **60 ~ 200 px**(icon 级)|
| 底板 | **二分:有底板(按钮型) vs 无底板(纯物品)** |

## 两个子类

## ⚠️ Variant 维度(2026-05-12 用户教学)

> S7 阶段一**不直接写 Variant**, S11 自动抽。 本节描述的 Variant 是 S11 抽完后预期看到的形态。

- **如果按钮有点击前后状态变化** → S7 不同状态按钮 fill 视觉不同, S11 自动切 [常态, 未激活态] 2 Variants
- 按钮单态(关闭/退出/设置 等) → S7 各实例视觉一致, S11 只出一个常态 Variant
- **附加角标/底标的多态** → S7 阶段一: 每个按钮都画完整角标 children, 不显示的写 `visible: false` (新 skill 07d 子 CCB 显隐铁律), S11 自动切空 Variant

## 子类划分

### A. 按钮型(底板 + 内嵌 icon)

底板形状 + 内 icon 的组合:

| 底板形状 | 例 | 推荐命名 |
|---|---|---|
| **圆底** | 蓝圆+齿轮(设置)/ 红圆+X(关闭)/ 蓝圆+i(信息) | `圆形按钮_<功能>` |
| **方圆角底** | 紫方+齿轮(设置)/ 蓝方+消息图 | `方形按钮_<功能>` |
| 椭圆底 | 大椭圆+活动 icon | `椭圆按钮_<功能>` |

**库已有匹配**(component_ref 可用):
- `圆形按钮_关闭` / `圆形按钮_退出` / `圆形按钮_信息` / `圆形按钮_设置` / `圆形按钮_播放[激活/禁用]` / `圆形按钮_加[激活/禁用]`
- `方形按钮_消息[激活/禁用]`
- `椭圆按钮_活动`

### B. 纯物品(无底板, 直接物品图)

- 没有底板背景, 就是物品本身的视觉(宝箱 / 钥匙 / 道具 / 食物 / ...)
- **数据驱动**(新 skill 07d 占位 RECT 规则), 用**占位 RECT** 名字 `图片_<物品名>` 或 `图标_<物品名>`
- 不抽 Component, 不做 Variant

## 识别信号(≥3 命中即匹配)

- [ ] **近正方形**(长宽比 0.85 ~ 1.15)
- [ ] **单一焦点**(1 个主 icon, 没有数字/文本附加)
- [ ] 边缘**没有角标溢出**
- [ ] **完整独立**(不附加在其他元素上, 没有横排数字底板拖在右边)
- [ ] 尺寸 **60 ~ 200 px**

## 区分相邻 pattern

| 看着像但不是 | 区别 | 实际属哪个 pattern |
|---|---|---|
| icon + 数字底板横排 | 右边带数字底板 → 不是单 icon | `横排徽章_左图右文` |
| icon + 右下/右上 小角标 | icon 上溢出小标识 → 不是单 icon | `角标_状态` 附加在 icon 上 |
| icon + 锁/对勾覆盖在中央 | 不属角标(在中心不是边缘) → 是主体本身的子图层 | 按主体处理(如宝箱_锁定 Variant) |

## 入 JSON 怎么写

### 子类 A(按钮型, 用库)

```json
{
  "component_ref": "圆形按钮_设置",
  "name": "按钮_设置",
  "w": 80, "h": 80,  // 缩放到场景尺寸
  "constraints": {"horizontal": "RIGHT", "vertical": "TOP"}
}
```

### 子类 B(纯物品, 占位 RECT)

```json
{
  "type": "RECTANGLE",
  "name": "图片_宝箱",  // 或 图标_宝箱
  "x": ..., "y": ..., "w": 120, "h": 120,
  "element_class": "static",
  "constraints": {"horizontal": "LEFT", "vertical": "TOP"}
}
```

(新 skill 07a #3 fill 规则: 手搓节点不写 fill, 插件按命名前缀自动分灰)
