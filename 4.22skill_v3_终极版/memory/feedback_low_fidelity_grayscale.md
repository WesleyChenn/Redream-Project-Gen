**铁律: 所有 RECT 占位填灰度色,不填游戏域具体颜色**(2026-05-20 用户明确)。

**Why**: 我们的产物是中间产物(scene.json),由插件粘到 Figma 后由设计师上色 / 美术替换图片。我若提前填颜色,反而让设计师返工。色板锁定灰度 4 阶:

| 用途 | 灰度色 |
|---|---|
| 屏背景 / 浮层底 | `#3a3a3a` 或 `#202020` |
| 容器底板 / 大面板 | `#888888` |
| 子件底板 / 按钮底 | `#aaaaaa` |
| icon 占位 / 头像占位 | `#cccccc` |
| 文本 fill | `#222222`(白底深字)/ `#eeeeee`(深底浅字) |

**禁用**: `#7ac84a` 绿 / `#d04848` 红 / `#d4a854` 金 / `#5acb50` 等所有指代具体颜色;**禁用饱和色**。

**How to apply**:
- 每个 R() 调用的 fill 参数只能取灰度 4 阶之一(或 None)
- TEXT fill 只能 `#222222` / `#eeeeee` / `#888888`
- 不为了"视觉效果好看"加颜色 — 占位是占位
- Variant 之间用形状 / 位置 / layers 差异区分,不用颜色区分
- 视频本身颜色五彩斑斓 ≠ scene.json 该上色;视频是数据,产物是结构
