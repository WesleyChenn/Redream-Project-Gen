# 进度条_横向 pattern

横向长条进度条。**新 skill 07c 已有强铁律(进度条三层结构)**, 本 memory 仅作识别快捷参考 + 补充常见组合形态。

## 5 维特征

| 维度 | 规律 |
|---|---|
| 形状 | 长条横向, 长宽比 **3:1 ~ 8:1**(显著比 `横排徽章` 更长)|
| 构成 | **必有 3 层** + 可选附加:`组_进度_X` FRAME 包 `底板_X` + `进度条_X` + 文本覆盖, 加可选 左icon / 右奖励/角标 |
| 位置 | 文本在进度条**中央覆盖**, 左 icon 上下溢出底板, 右附加在底板外侧 |
| 量级 | 底板 w **≥ 200 px**(中-大尺寸)|
| 底板 | **必须有**(底板 RECT + 进度条 RECT) |

## 进度条本体 新 skill 07c 铁律(必跟)

```
外层容器: 按钮_X 或 组_X
├── (可选) 图标_左 (RECT/INSTANCE, 上下溢出底板)
├── 组_进度_X (FRAME 包装层 — 新 skill 07c 铁律)
│   ├── 底板_X (RECTANGLE, 100% 满模板, 大尺寸内缩 10px)
│   └── 进度条_X (RECTANGLE, 100% 满模板, 中心对齐底板)
├── 文本_X (TEXT, 居中覆盖, "X/Y" 格式 dynamic)
└── (可选) 角标_X 或 图片_奖励 (右侧外置)
```

⚠️ 进度条本体**不写百分比**,引擎运行时按数据 CCProgressTimer 切。  
⚠️ 进度条 RECT **必须比底板小**(横纵内缩, 新 skill 07c 铁律 4.5)。

## 🔴 引擎硬性要求(2026-05-12 用户强调)

**进度条节点 name 必须以 `进度条_` 开头**, 引擎才把它识别为 `CCProgressTimer`。

```
✅ 节点 name = "进度条_体力" / "进度条_经验" / "进度条_经验_tb"
❌ 节点 name = "填充_体力" / "progress_xx" / "进度填充_xx" 
   → 引擎不识别, 变成普通 RECT, 进度条机制失效
```

外层包装 FRAME 名 = `组_进度_<XXX>`(进度二字在外层), 内部进度条 RECT name = `进度条_<XXX>`, 内部底板 RECT name = `底板_<XXX>`(不带"进度")。 三层 XXX 必须完全一致。

|---|---|---|
| **A. 纯进度条** | 仅本体 + 文本 | image 5 "1/3" |

## 识别信号(≥3 命中即匹配)

- [ ] **长宽比 ≥ 3:1**(显著长条)
- [ ] 有**双层 RECT** 视觉(底板灰/暗 + 内层填充亮色, 内层比底板略小)
- [ ] 文本**居中覆盖**进度条(不在左不在右)
- [ ] 文本格式 **X/Y**(数字 / 数字)
- [ ] 可能伴随左 icon **上下溢出** / 右奖励 / 右角标

## Component 命名

按 新 skill 07c 命名铁律:

| 节点 | 命名 |
|---|---|
| 包装 FRAME | `组_进度_<语义>`(例: `组_进度_体力`)|
| 底板 RECT | `底板_<语义>`(例: `底板_体力`)|
| 进度条 RECT | `进度条_<语义>`(例: `进度条_体力`)|
| 文本 | `文本_<语义>_进度`(例: `文本_体力_进度`) |
| 三层 XXX **必须完全一致** | "进度"二字**只出现在外层包装**, 内部底板/进度条不带 |

**外层容器命名**:
- 可点击 → `按钮_<语义>` FRAME(新 skill 07c 铁律 6)
- 仅展示 → `组_<语义>` FRAME

## 文本格式不进 Variant

"3/5" "5/9" "8/9" 等数值 → S7 直接写每实例 TEXT.content 实际值, S11 自动收集到 INSTANCE.overrides, 不抽 Variant (S6 #3 Variant 例外: 数据驱动不抽 Variant)。

## 反面案例

| 看着像但不是 | 区别 |
|---|---|
| `横排徽章_左图右文` | 中间无双层填充, 是单一文本底板 |
| 单图标 / 角标 | 不是长条 |
| 不带文本的进度条 | 跟带"X/Y"文本的常见进度条略不同, 但仍套此 pattern(文本可空)|

## 入 JSON 怎么写(模板)

```json
{
  "type": "FRAME",
  "name": "按钮_体力进度",                   // 整体可点击 → 按钮_; 否则 组_
  "x": ..., "y": ..., "w": 400, "h": 80,
  "element_class": "static",
  "constraints": {"horizontal": "SCALE", "vertical": "TOP"},
  "layoutMode": "NONE",
  "children": [
    {
      "type": "RECTANGLE", "name": "图标_红心",     // 可选左 icon (上下溢出)
      "x": -20, "y": -15, "w": 100, "h": 110
    },
    {
      "type": "FRAME", "name": "组_进度_体力",      // 进度条包装层(新 skill 07c 铁律)
      "x": 60, "y": 10, "w": 280, "h": 60,
      "children": [
        {
          "type": "RECTANGLE", "name": "底板_体力",
          "x": 0, "y": 0, "w": 280, "h": 60,
          "corner_radius": 30
        },
        {
          "type": "RECTANGLE", "name": "进度条_体力",
          "x": 10, "y": 10, "w": 260, "h": 40,
          "corner_radius": 20
        }
      ]
    },
    {
      "type": "TEXT", "name": "文本_体力_进度",
      "x": 150, "y": 25, "w": 100, "h": 30,
      "element_class": "dynamic",
      "content": "0/0", "font_size": 30, "font_weight": "Bold"
    }
  ]
}
```
