用户项目里"盾牌等级"组件的**典型 layout 是大盾牌外凸 + 右侧胶囊数字**,**不是方块内数字**。

## 高保真标准结构

```
┌────────────────────┐
│  ╔════╗            │
│  ║盾牌║  ┌──────┐  │  ← 盾牌左, 数字胶囊在右
│  ║图案║  │ 247  │  │  ← 盾牌上下溢出底板边界
│  ╚════╝  └──────┘  │
└────────────────────┘
```

视觉特征:
- 盾牌图标**显著大**,占整体高度 100%+(上下溢出 row 底板)
- 盾牌位于**左半部**, 数字在**右半部**
- 数字外有圆角胶囊底板(深色), 与 row 主底板形成对比
- 整体**横向布局**, w > h(约 2:1)

## 低保真简化版

**保留盾牌外凸 + 数字右胶囊**结构:
```
- INSTANCE 盾牌图标 (RECT 占位)           x=0,    y=溢出量上,  w=parent_w*0.4, h=parent_h+2*溢出
- 底板_数字 (RECT 圆角, 深色)              x=parent_w*0.5, y=10, w=parent_w*0.5, h=parent_h-20
- TEXT 文本_数字                          位于底板_数字 中心
```

**不要做成**:
- ❌ 单一方块 + 数字在内(那是更简化的另一种 layout)
- ❌ 数字+图标横排,无独立胶囊

**Why**:
- 2026-05-12 上午用户给了截图(盾牌_247), 我重建成"蓝方块+数字在内" — 完全丢失盾牌+独立数字胶囊的结构
- 这种 layout 在用户项目里**高频出现**(排行榜行右侧"等级/分数"几乎全是这个款)

**How to apply**:
- 遇到"盾牌图案 + 数字"的等级/分数徽章 → 默认套"盾牌左凸 + 右胶囊数字"
- 看到数字外有独立圆角胶囊 → 强信号是这个结构, 不是单方块内嵌数字
- 排行榜行最右侧的"等级显示" → 几乎一定是这个款
