## constraints (大组团位置语义)

按 SKILL.md 铁律 #14:

| 大组团 | constraints |
|---|---|
| 遮罩_浮层背景 | `SCALE/SCALE` (唯一例外, 全屏遮罩) |
| 装饰头 | `CENTER/TOP` |
| 组_标题 | `CENTER/TOP` |
| 组_顶部HUD | `CENTER/TOP` |
| 组_卡片区 | `CENTER/TOP` (内容居中, 上对齐) |
| 装饰_箭头左 ×3 | `LEFT/TOP` |
| 装饰_箭头右 ×3 | `RIGHT/TOP` |
| 按钮_关闭 | `RIGHT/TOP` (顶 HUD 内部按 NONE 父定) |

AL 子节点 (组_卡片区 内的行,行内的 INSTANCE,列表项_offer 内部 layer 等) **不写 constraints**。

## layoutMode 合约 → S7 (重要)

- `组_标题` = VERTICAL AL → S7 写 VERTICAL AL 完整字段, **不许退化 NONE 手算 y**
- `组_卡片区` = VERTICAL AL → 同
- `组_行N` = HORIZONTAL AL → 同
- `列表项_offer` 内部 = VERTICAL AL (奖励物上 / 按钮下) → 同
- `奖励物_多` 内部 = HORIZONTAL AL → 同
- `单个奖励物` 内部 = VERTICAL AL (icon 上, 文本下) → 同
- `按钮_offer` 内部 = NONE (S3 判定: 文本居中底板, 视觉是叠加,不是横/竖排)
