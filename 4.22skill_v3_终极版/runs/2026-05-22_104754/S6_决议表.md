## ccb/多态决议表 🔴

```
abstract_ccb 1: 列表项_offer
  复用次数: 6 (主屏 6 个 INSTANCE)
  3 标准命中: 复用 ≥3 ✓
  variant_axes: (无, 1 默认 variant — 差异下沉到子 ccb)
  default variant 名: 默认
  内部 layers:
    - INSTANCE 奖励物 (子 ccb)
    - INSTANCE 按钮_offer (子 ccb)
    - INSTANCE 角标_锁 (子 ccb, 右上溢出)

abstract_ccb 2: 奖励物
  复用次数: 6 (列表项_offer 内 1 处, 6 个 INSTANCE)
  3 标准命中: 复用 ≥3 ✓ + 动态 (运行时填道具种类)
  variant_axes: count [单/多]
  variants:
    - 单奖励物: 1 个 INSTANCE 单个奖励物 (居中)
    - 多奖励物: 2-3 个 INSTANCE 单个奖励物 (HORIZONTAL AL 横排)

abstract_ccb 3: 按钮_offer
  复用次数: 6
  3 标准命中: 复用 ≥3 ✓
  variant_axes: (无, 1 默认 variant — 文案/颜色走 override)
  default variant 名: 默认
  内部 layers:
    - 底板_按钮 (RECT, 绿/橙底, 颜色 override)
    - 文本_按钮 (TEXT, "FREE"/"£2.99" 等 override)
    - icon_小锁 (RECT, 按钮文字右侧, 可 visible:false override)

abstract_ccb 4: 角标_锁
  复用次数: 6 (5 个挂锁 + 1 个空, 即"£2.99" 那张不挂)
  3 标准命中: 复用 ≥3 ✓
  variant_axes: 状态 [锁/空]
  variants:
    - 锁: 绿圆 + 白锁 icon
    - 空: layers: []  ← 不显示该状态

abstract_ccb 5: 单个奖励物
  复用次数: ≥10 (1 + 2 + 1 + 3 + 1 + 1 = 9, 但抽象上是每个奖励物都用一个 INSTANCE → 9 处)
  3 标准命中: 复用 ≥3 ✓ + 动态 (运行时填道具图)
  variant_axes: 类型 [金币/道具]
  variants:
    - 金币_文本: 金币堆 icon + 数字 TEXT (无 "×", 如 "3000" / "200")
    - 道具_文本: 道具 icon + "×N" TEXT (如 "×1" / "×2")
```
