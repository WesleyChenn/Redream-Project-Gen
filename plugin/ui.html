⛔ INSTANCE 尺寸与 Component 本体不一致
📌 修复方式选择

情况 A：所有尺寸应该是同一个（设计师误拖了边框）
→ 在屏幕里选中目标尺寸的那个 INSTANCE → 点下方 「🔁 用选中 INSTANCE 同步全部尺寸」
插件会把 main Component + 所有同源 INSTANCE 都同步到此尺寸。

情况 B：不同尺寸代表不同 Variant（如"大档/小档"两个版本）
→ 选中所有需要拆分的 INSTANCE（≥2 个）→ 点下方 「📐 按尺寸拆分为多个 Variant」
插件会按尺寸分组：实例数最多的尺寸保留原 Variant，其余尺寸 clone 出新 Variant 并把对应 INSTANCE 重指向。

替代方案（手动）：去 📦_组件库 直接改 Component 本体 W/H → 框选屏幕里所有 INSTANCE → 右键 Reset all changes。
