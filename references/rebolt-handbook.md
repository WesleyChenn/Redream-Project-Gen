# Rebolt 使用手册

来源：Notion「Rebolt 使用手册」导出（基于 Redream V1.4.8 - V9.4.4）

---

## 概述

**Rebolt** 是集成于 Redream 内的**可视化逻辑编辑工具**，采用类 Scratch 的积木式编程，将复杂代码转化为拖拽组合操作，用于快速实现动画播放、界面元素位移、动态文本赋值等逻辑。

---

## 一、积木块型分类

| 块型 | 形状 | 作用 |
|------|------|------|
| **事件积木** | 顶部圆弧形 | 逻辑的唯一入口，启动下方连接的积木逻辑 |
| **命令积木**（堆叠积木） | 顶凹下凸 | 执行具体命令，可上下拼接 |
| **判断积木** | 六边形 | 逻辑判断返回布尔值，需嵌入判断槽使用 |
| **参数积木** | 椭圆形 | 数据存储和传递，需嵌入参数槽使用 |
| **流程控制积木** | C 形 | 控制循环和条件分支 |

## 二、事件类积木

### 2.1 按钮
| 积木 | 说明 |
|------|------|
| **按钮点击** | 监控按钮点击，点击时执行下方逻辑 |
| **启/禁用按钮** | 根据复选框设置按钮启用/禁用。禁用后失去"防穿透"效果 |

**常用按钮逻辑结构**：禁用按钮 → 通知程序 → 执行逻辑 → 等待 → 恢复按钮

### 2.2 消息（已逐渐停用）
| 积木 | 说明 |
|------|------|
| **当接收到消息** | 监控全局消息，收到时执行逻辑 |
| **广播消息** | 发送全局消息（需在菜单栏 Rebolt 标签中添加） |

### 2.3 通知工程师
| 积木 | 说明 |
|------|------|
| **通知工程师** | 告诉程序逻辑运行到哪了，常用于让程序执行函数 |
| **通知工程师_参数** | 额外传递一个参数 |
| **通知工程师_参数_Node节点** | 额外传递一个节点，建议放在单独的"绑定节点"函数下 |
| **通知工程师_等待手动回调** | 通知的同时暂停逻辑，等程序回调后恢复 |
| **通知工程师_等待手动回调_参数** | 带参数版本 |
| **通知工程师_等待手动回调_参数_Node节点** | 带参数和节点版本 |
| **通知工程师_更新所有程序变量** | 把整个 Rebolt 给到程序，允许对"程序变量"动态赋值 |

**CLI 对应规则（当前）**：
- 节点引用类通知/控制块写 selector 时，`Value` 用 live `reboltId`，`DisplayName` 用 live `reboltName`
- 按钮点击块 `BTButtonClickFuncAction` 使用 `mathSelector`；大多数其他节点块使用 `baseSelect`
- 用 CLI 改 `.rebolt` 前，先确认 paired `.red` 中目标节点存在，且 `reboltName` 不为空

## 三、控制类积木

### 3.1 等待
| 积木 | 说明 |
|------|------|
| **等待** | 逻辑暂停指定时间，会暂停目标 CCB 正在播放的时间线 |

**重要提示**：制作"弹出 N 秒后自动关闭/点击空白提前关闭"时，应使用**时间线空白部分**代替等待积木，因为等待积木**无法被打断**。

### 3.2 条件判断
| 积木 | 说明 |
|------|------|
| **如果那么** | 条件成立时运行内部逻辑 |
| **如果那么_否则** | 条件成立运行上部，不成立运行下部 |

### 3.3 循环
| 积木 | 说明 |
|------|------|
| **重复执行_直到条件满足** | 条件循环，持续执行直到条件成立 |
| **重复执行_次数** | 计数循环，执行指定次数 |

## 四、时间线类积木

### 4.1 播放时间线
| 积木 | 说明 |
|------|------|
| **异步播放** | 播放不影响后续逻辑，可并行运作。同一 CCB 下同时只能播一条时间线 |
| **同步播放** | 播放会阻断后续逻辑直至播完。即使自循环也会在播完一次后继续推进 |
| **异步播放_播完执行函数** | 不影响后续逻辑，播完后执行支线函数。兼具灵活性和时序安全 |

**关键规则**：同一 CCB 下的不同时间线同时只能播放一条，后面的会**强制替代**前面的。

### 4.2 暂停时间线（目前有 BUG）
| 积木 | 说明 |
|------|------|
| **停止播放** | 存在 BUG：不论选择哪条，都会暂停目标 CCB 正在播放的时间线 |
| **停止播放全部时间线** | 效果与"停止播放"基本相同，仅停止本 CCB 不影响子 CCB |

## 五、变量类积木

### 5.1 全局变量（已逐渐停用）
- 同一工程中任意 CCB 都可调用，不需要基于 CCB 嵌套
- 需在菜单栏 Rebolt 标签中添加

### 5.2 程序变量
| 积木 | 说明 |
|------|------|
| **程序变量** | 程序人员向 Rebolt 动态传递参数的主要途径 |
| **设置程序变量（模拟程序）** | 模拟程序赋值，可对子 CCB 程序变量赋值 |

**提示**：
- 参数传递有"程序变量"和"自定义函数参数"两种，尽量避免混用
- 复杂大工程应尽量使用程序变量
- 子 CCB 有程序变量时，需使用"通知工程师_更新所有程序变量"

### 5.3 自定义变量
| 积木 | 说明 |
|------|------|
| **自定义变量** | 本地使用变量，内部存储和传递数据，程序无法使用 |
| **将自定义变量设置为** | 直接设置变量值 |
| **将自定义变量增加** | 在当前值基础上增加（负数即为减少） |

### 5.4 自定义数组（目前无法使用，建议避免）
- 存储多个相同类型元素的有序集合
- 支持：添加、删除、插入、替换、查询编号、计数、包含判断

## 六、运算类积木

### 6.1 算术运算
- 加/减/乘/除
- **注意**：结果默认保留小数点后 6 位，应配合"保留小数"或"取整"使用

### 6.2 关系运算
- 大于/等于/小于（仅支持数值，不允许字符串）

### 6.3 逻辑运算
| 积木 | 说明 |
|------|------|
| 真/假 | 直接输出布尔值 |
| 与 | 两侧都为真才输出真 |
| 或 | 一个为真就输出真 |
| 不成立 | 对判断结果取反 |

### 6.4 字符操作
| 积木 | 说明 |
|------|------|
| **连接** | 连接两个字符串，可多个叠加 |
| **字符串的长度** | 中文字符=3，英文字符=1 |
| **字符串是否包含？** | 判断是否包含子串 |
| **字符串是否等于？** | 判断两串是否完全一致 |

### 6.5 数学方法
| 积木 | 说明 |
|------|------|
| **取随机数** | 在两个参数间随机取值，配合"保留小数"使用 |
| **取余数** | 常用于判断周期性/整除性 |
| **取整** | <0.5 向下取整，≥0.5 向上取整 |
| **更多取值** | 绝对值、向下/向上取整、平方根、三角函数、对数等 |
| **保留小数** | 设定输出保留的小数位数，0 = 不显示小数 |

## 七、自定义函数

### 创建方式
选择"自制函数"分类 → "添加一个函数" → 输入名称 → 可添加参数（数字/文本/布尔值）

### 两种形态
| 形态 | 说明 |
|------|------|
| **事件积木** | 逻辑起点，程序人员调用的主要接口 |
| **命令积木** | 执行同名自定义函数（创建后自动出现在侧边栏） |

### 关键提示
- 函数参数只能用在对应函数内部（与程序变量不同）
- 父 CCB 调用子 CCB 的函数：需给子 CCB 起 **Rebolt Name**，并在右下角打勾保存
- 删除函数前需确保**整个工程中没有该函数的调用**

## 八、外观 UI 类积木

### 8.1 节点显隐
| 积木 | 说明 |
|------|------|
| **显示/隐藏自己** | 设置 CCB 中所有节点的可见属性 |
| **显示/隐藏_特定节点** | 设置指定节点的可见属性 |
| **是否隐藏？** | 根据显隐状态输出布尔值 |

**重要规范**：
- 在 Redream 中对可见属性 K 帧的节点**无法被 Rebolt 控制**，需用颜色标记（通常黄色）
- 互斥节点显隐应通过 Rebolt 控制，**避免在 Redream 中预设隐藏**

### 8.2 Label 节点
| 积木 | 说明 |
|------|------|
| **Label** | 设置文字节点的文本内容 |
| **Label更新占位符内容** | 多语言动态文本，支持 `#!1` ~ `#!4` 四个占位符 |

### 8.3 进度条
| 积木 | 说明 |
|------|------|
| **进度条** | 直接设置进度条百分比（0-100） |

### 8.4 坐标
| 积木 | 说明 |
|------|------|
| **X/Y坐标** | 获取节点本地坐标（设置坐标时用） |
| **全局X/Y坐标** | 获取全局坐标（设置飞行动画时用） |

### 8.5 属性设置
| 积木 | 说明 |
|------|------|
| **设置坐标** | 设置节点坐标（本地坐标） |
| **设置旋转** | 设置旋转角度 |
| **设置缩放** | 设置 X/Y 缩放倍数 |

### 8.6 Sprite
| 积木 | 说明 |
|------|------|
| **Sprite_单图** | 依图片路径设置精灵图（未打包的背景图等） |
| **Sprite_Plist** | 依 Plist 路径设置精灵图（打包后的 UI 资源） |

**CLI 对应规则（当前）**：
- `Sprite_单图` → `BTSpriteImageAction`，写 `TitleInput`
- `Sprite_Plist` → `BTSpritePlistAction`，写 `pathInput` + `frameNameInput`
- 不要把单图路径硬写进 plist 块，也不要把 plist/frame 拆成单图块

## 九、声音类积木

### 播放 Wise 事件
- **参数1**：.bnk 文件名（含后缀）
- **参数2**：Wise 事件名（Event）

### 两种播放方式
| 方式 | 适用场景 |
|------|----------|
| 绑定在时间线上（K 帧） | 较短的反馈音效 |
| 通过音频积木块直接播放 | 较长的背景音乐 |

**注意**：
- 同一 .bnk 文件中不同 Wise 事件默认**不互斥**，可与音频人员沟通设置互斥
- Rebolt 预览器（9.4.4）**无法预览** Wise 事件

## 十、节点动画类积木

### 10.1 Label 数字动画
- 参数：总时长 / 起始值 / 结束值

### 10.2 进度条动画
- 参数：总时长 / 起始值 / 结束值

| 积木 | 说明 |
|------|------|
| **模拟程序执行** | 当"通知工程师"执行时自动触发，模拟程序端行为 |

## 十三、换图逻辑

### 应用场景
相同位置需依条件动态切换图片时，使用 Sprite 积木实现（如关卡弹窗底板适配不同难度等级）。避免预置多张图片通过显隐切换，降低资源量和加载耗时。

### 两种写法选择

| 写法 | 方式 | 优点 | 缺点 | 适用场景 |
|---|---|---|---|---|
| 旧写法 | 程序通过「程序变量」传递 plist 名和图片名给 Sprite 积木 | 灵活、结构简洁 | 资源维护需产品配合改配表 | 单节点大量/频繁换图（如道具） |
| 新写法 | 在积木块中写死图集/图片名，Rebolt 中枚举所有可能图片 | 与其他岗位耦合低 | 灵活性差，资源量大时制作成本高 | 单节点 ≤5 个替换资源 |

**选择规则**：单节点 >5 个替换资源 → 旧写法（程序变量传递），≤5 个 → 新写法（Rebolt 枚举）

**实现方式**：旧写法使用 `BTCoderVariableAction` 读取 C++ 注入的 P-变量，再按真实资源合同选择积木：
- 运行时给的是单图路径（或 plist 允许为空）→ `BTSpriteImageAction`，写 `TitleInput`
- 运行时给的是 plist + frame 名 → `BTSpritePlistAction`，写 `pathInput` + `frameNameInput`

详见 `references/rebolt.md`。
