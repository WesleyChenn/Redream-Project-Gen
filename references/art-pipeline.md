## 管线概述

美术组开发管线分为两条路径，根据项目类型选择：

---

## 一、自研/复杂项目

三条并行工作流：

### 上线（中级工程美术）
```
工程结构说明文档 → Rebolt工程 → Rebolt接口文档 → 交付开发
```

### 中线（初级工程美术）
```
交互原型切图 → 美术原型工程 → UI终稿切图 → 最终换图工程
```

### 下线（设计师）
```
交互设计图(交互设计师) → UI设计图(UI设计师)
```

### 流程说明
- **交互设计师**提供交互设计图，UI 设计师据此产出 UI 设计图
- **中级工程美术**负责工程结构说明文档、Rebolt 工程搭建和接口文档
- **初级工程美术**负责交互原型切图、美术原型工程、UI 终稿切图、最终换图工程
- 上线和中线汇合后→**交付开发**

---

## 二、复刻/简单项目

三条并行工作流：

### 上线（中级工程美术）
```
交互拆解图 → 工程结构说明文档 → Rebolt工程 → Rebolt接口文档 → 交付开发
```

### 中线（初级工程美术）
```
截图原型切图 → 美术原型工程 → UI终稿切图 → 最终换图工程
```

### 下线（UI 设计师）
```
UI设计图
```

### 与自研项目的区别
| 对比项 | 自研/复杂项目 | 复刻/简单项目 |
|--------|--------------|--------------|
| 交互设计 | 交互设计师提供交互设计图 | 中级工程美术直接做交互拆解图 |
| 原型切图 | 交互原型切图 | 截图原型切图 |
| UI 设计 | 交互设计师 + UI 设计师配合 | UI 设计师独立完成 |

---

## 三、角色职责

| 角色 | 颜色标识 | 职责 |
|------|----------|------|
| 交互设计师 | 紫色 | 交互设计图 |
| UI 设计师 | 粉色 | UI 设计图 |
| 中级工程美术 | 黄色 | 工程结构说明文档、Rebolt 工程、Rebolt 接口文档、交互拆解图 |
| 初级工程美术 | 绿色 | 交互/截图原型切图、美术原型工程、UI 终稿切图、最终换图工程 |

---

## 四、关键交付物

| 交付物 | 负责人 | 说明 |
|--------|--------|------|
| 工程结构说明文档 | 中级工程美术 | 定义工程整体结构 |
| 交互原型切图 / 截图原型切图 | 初级工程美术 | 基于交互设计的切图资源 |
| 美术原型工程 | 初级工程美术 | 初步搭建的工程原型 |
| Rebolt 工程 | 中级工程美术 | 行为树逻辑工程 |
| UI 终稿切图 | 初级工程美术 | 最终 UI 设计的切图资源 |
| 最终换图工程 | 初级工程美术 | 换入终稿切图后的完整工程 |
| Rebolt 接口文档 | 中级工程美术 | Rebolt 与程序对接的接口说明 |
