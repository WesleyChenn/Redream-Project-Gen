# 字体资源规范

来源：字体资源规范.pdf

---

## 核心理念

将**字体样式**和**字体本身**分开输出，在工程内上下叠加实现多种视觉效果：
- 纯色字体 → 输出纯白色字体，工程内调色
- 渐变色字体 → 输出灰色渐变层，工程内调色
- 描边/其他样式 → 输出纯白色样式字体，工程内调色

---

## 一、前期设计

- **字体**：确保字形统一，一个项目只用一个字体（如 Mikado）
- **字号**：配合应用界面灵活调整
- **注意**：
  - 整个工程字体样式不宜过多
  - 做字体样式时保证美观且工程内可实现

---

## 二、资源制作

### 2.1 字号标准
- **标准字号：100**（满足大部分字体需求，特殊情况另作处理）

### 2.2 字体和样式制作

#### 案例1：纯色字体 + 描边样式
1. 制作纯色字体时，给字体加**透明度 0% 的描边**占位
2. 制作描边样式资源：字号 50 的纯白色字体 + 纯白色描边
3. 输出：
   - 字体：纯白色（字体和描边都纯白，描边透明度 0%）
   - 样式：纯白色样式字体资源

#### 案例2：纯色字体 + 描边阴影样式
1. 字体加透明度 0% 的描边占位
2. 制作样式：字号 50 纯白色字体 + 纯白色描边 + 灰色阴影
3. 输出：
   - 字体：纯白色（字体/描边/阴影都纯白，透明度 0%）
   - 样式：纯白色描边 + 灰色阴影样式

#### 案例3：渐变字体
1. 字体加透明度 0% 的描边占位
2. 输出：
   - 字体（纯色）：字体和描边都纯白，描边透明度 0%
   - 字体（渐变）：字体灰色渐变，描边纯白透明度 0%
   - 样式：纯白色样式字体资源

**关键规则**：描边样式的描边尺寸与字体 0% 透明度描边尺寸**必须完全相同**

### 2.3 字体资源输出

- **最终输出格式**：webp
- **命名格式**：`项目名称_字体/字体样式_具体描述`
  - 示例：`项目名称_字体_渐变字体`、`项目名称_字体样式_描边`
  - 完整命名列表：
    - `项目名称_描边字体_纯色字体`
    - `项目名称_描边字体_渐变字体`
    - `项目名称_描边样式`
    - `项目名称_描边外投影字体_纯色字体`
    - `项目名称_描边外投影字体_渐变字体`
    - `项目名称_描边外投影样式`

### 2.4 png 转 webp
1. 使用压缩工具
2. 将 png 图片拖入新文件夹
3. 打开批量压缩工具 → 拖入文件夹 → 点击转换
4. 将 webp 图片拖回 `_fonts` 文件夹
5. 清理临时文件夹

### 2.5 修改 .fnt 文件
- 用 Sublime 打开 .fnt 文件
- 将文本中的 `png` 改为 `webp`（注意不要删除前面的 `.`）
- `Ctrl+S` 保存

## 三、字体应用（工程内）

以弹窗标题为例：
1. 在标题组新建「标题文本」node
2. 先放「文本样式」：
   - 坐标：**50%, 50%**（硬规定）
   - 对齐方式：**左右居中, 上下居中**（硬规定）
3. 再放「文本」：
   - 坐标：**50%, 50%**（硬规定）
   - 对齐方式：**左右居中, 上下居中**（硬规定）

**调整位置/大小时**：调整上层「标题文本」node，不要动里面的内容

## 四、检查清单

### 资源制作环节
- [ ] 字体和字体样式各属性数值是否一致？
- [ ] 字号大小是否一致？
- [ ] 描边数值是否一致？
- [ ] 外描边还是内描边？
- [ ] 阴影扩散数值是否一致？

### 工程应用环节
- [ ] 所有字体是否在同一个文本 node 内？
- [ ] 坐标是否设为 50% 50%？
- [ ] 对齐方式是否为上下居中、左右居中？

## 五、常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 字体显示为纯白小字无样式 | 工程未读取到字体文件 / .fnt 内容未改 webp | 重启工程 / 修改 .fnt |
| 文本和样式对不齐 | 工程未加载 / 属性数值不同 | 重启工程 / 检查属性一致性 |
| 缩小带描边字体异常 | 未同时缩小描边数值 | 缩小字体时同步缩小描边数值 |
