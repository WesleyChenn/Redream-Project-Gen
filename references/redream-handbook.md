# Redream 使用手册

来源：Notion「Redream 使用手册」导出（基于 Redream V1.3.15.1+）

---

## 一、界面结构

Redream 编辑器分为五大区域：

| 区域 | 名称 | 功能 |
|------|------|------|
| A | 功能区 | 节点栏、工具栏、菜单栏 |
| B | 场景区 | 场景编辑器和项目页签 |
| C | 文件区 | 显示项目资源 |
| D | 动画区 | 节点管理器和时间线面板 |
| E | 属性区 | 编辑节点属性 |

## 三、功能节点大全

### 3.1 基础节点

#### 节点 CCNode（高频）
- 不可显示的空节点，用作根节点或组
- 在 Node 里放图片、字体等产生父子级关系

#### 空层 CCLayer（基本不用）
- 比节点多一个 CCLayer 模块，可当根节点或组

#### 安全区域 RedSafeAreaLayer（较频繁）
- 适配全面屏手机，自动布局适配子节点
- 所有可能被摄像头模组遮挡的界面都需部署

#### 点击屏蔽层 CCBlockTouchLayer（一般）
- 阻止点击事件穿透到下层元素
- 弹窗遮罩常用，也可用无点击效果的按钮代替

---

### 3.2 图像节点

#### 精灵图 CCSprite（高频）
- 游戏基础视觉元素
- 属性：纹理、翻转X/Y轴、混合、翻转复制
- **翻转复制**：对称图片无需两个节点拼接

#### 九宫格精灵图 CCScale9Sprite（较频繁）
- 缩放矩形图像保留细节
- 四角不变，其他部分拉伸或平铺
- 主要用于 UI 元素和按钮

#### 多边形精灵图 Polygon Sprite（基本不用）
- 分为三角形提高性能，功能尚不完善

#### 多语言精灵图 CCSpriteI18n（较频繁）
- 一个节点绑定多张不同语言图片
- 根据游戏语言自动切换显示
- 常用于标题等艺术字资源的多语言适配

---

### 3.3 文本节点

#### 位图字 CCLabelBMFont（较频繁）
- 点阵字符，性能好但不适合缩放（会失真）
- 需要 .fnt 字体文件
- 包含样式管理和语言优化功能

#### 双位图字 CCRedLabel（较频繁）
- 位图字衍生，一个节点同时叠加两种字体
- 前景字体 + 背景字体控制
- 保证对齐关系并简化逻辑

#### 系统字 CCLabelTTF（一般）
- 比位图字更灵活，可随意缩放不失真
- 不需为每种尺寸/颜色单独字体文件
- 缺点：渲染速度较慢，更改属性时消耗性能

---

### 3.4 UI 控件

#### 按钮 REDNodeButton（较频繁）
- 响应用户点击，主要功能：
  - 按下缩放
  - 移动取消点击
  - 吞噬触摸事件
  - 首选尺寸设定
  - 按下/抬起 Wise 事件
- 文本、背景等内容需放入按钮节点之下

#### 按钮（旧版）CCControlButton（基本不用）
- 仅为适配旧文件，应使用新版按钮

#### 菜单项/图片菜单项 CCMenu/CCMenuItemImage（基本不用）
- 设定菜单项不同状态的显示图片
- 实际工作中使用频率很低

#### 复选框 UICheckBox（基本不用）
- 两种状态切换，用于问卷/游戏设置

#### 进度条 CCProgressTimer（较频繁）
- 条形/扇形两种类型
- 通过 Midpoint 控制起点
- 通过 rChangeRate 控制方向

#### 滑动条 UISlider（基本不用）
- 从预定范围设置数值，如音量控制

#### 单行输入框 UIEditBox（基本不用）
- 文本输入，支持占位文本、密文、输入模式预设

---

### 3.5 图层节点

#### 单色层 CCLayerColor（较频繁）
- 区域内显示单色，多用于遮罩/转场

#### 渐变层 CCLayerColor-Gradient（一般）
- 区域内显示两色渐变
- 属性：开始颜色/透明度、结束颜色/透明度、渐变方向

#### 蒙版 MatteNode（一般）
- 通过裁切图像指定裁切区域
- 支持 Alpha、Luma 等算法及反向显示
- Mask 节点下放裁剪形状，Background 节点下放显示内容

#### 多边形蒙版 REDPolygonClippingNode（一般）
- 通过绘制包围盒裁切，支持反转显示
- 功能尚不完善

#### 滚动层 CCScrollView（较少用）
- 可滚动翻阅的容器，功能尚不完善
- 一般由程序端实现

#### 列表 CCTableView（较少用）
- 显示项目列表，功能尚不完善
- 一般由程序端实现

---

### 3.6 动画节点

#### 序列帧动画 ZGFrameActionSprite（一般）
- 依次播放关键帧实现动画
- 需要 .webp 等打包格式文件
- 指定纹理前缀名称和纹理下标
- 也可通过 CCSprite 完成

#### 粒子系统 RParticleSystem（较频繁）
- 模拟火、烟、液体等动态效果
- 核心模块：发射、形状、生命周期速度/颜色/大小/旋转、外力、子发射器
- 支持曲线编辑控制属性随时间变化
- 曲线播放模式：Loop / Ping Pong / Clamp

#### Spine 骨骼动画 SkeletonAnimation（较频繁）
- 需要：.json/.skel（骨骼数据）+ .atlas（图集数据）+ .webp/.png（纹理）
- 支持皮肤选取、循环播放、骨骼/插槽显示
- **无法在 Redream 中编辑**，只能预览和播放

#### Spine 烘焙文件 RedBakeNode（基本不用）
- 大量重复骨骼动画时节省性能
- 实际使用极少

---

### 3.7 引用节点

#### RED 文件 REDFile（高频）
- 在工程中嵌入另一个 .red 文件
- 类似智能对象：子文件编辑同步至母文件，母文件操作不影响子文件
- 支持多时间线选择

## 四、动画制作要点

### 时间线
- 设置总时长（帧数）
- 在关键帧位置插入属性变化（坐标、透明度、缩放等）
- 支持多条时间线（常态、切换动画等）

### 动效预设
| 预设 | 效果 |
|------|------|
| EasingBackOut | 弹性回弹（弹出） |
| EasingBackIn | 弹性回弹（收入） |
| EasingElasticOut | 弹性振荡 |

### 弹窗动画标准
- **弹出动画**：遮罩透明度 0→目标值 + 弹窗缩放 0→1
- **退出动画**：内容全部隐藏
- **常态**：内容正常显示

### 循环动画
- 第一帧和最后一帧大小位置必须相同
- 支持自动循环设置

## 五、项目文件结构

| 文件夹 | 设计用（原始文件） | 程序用（导出文件） | 说明 |
|--------|-------------------|-------------------|------|
| 工程文件 | ccb (.red/.rebolt) | _ccbi (.redream) | 设计完成后导出 |
| 配表文件 | — | _config | .csv/.json/.plist |
| 字体文件 | _font | _font | .webp + .fnt 成对使用 |
| 图集文件 | image + tps | _img_plist | .webp + .plist |
| 单图文件 | — | _img_single | 尺寸较大无需打包的图 |
| 音频文件 | sound (.mp3) | _redwise (.bnk) | 音频部门提供 |
| 骨骼动画 | — | _spine | .skel + .atlas + .webp |

**核心规则**：带下划线 `_` 的文件夹是交付程序的，不带下划线的是设计协作用的。

### .fnt 字体文件
- .webp 文件 = 存放文字的"货架"
- .fnt 文件 = 货架清单，用于快速调用文字

### 图集打包流程
image 散图 → TP (Texture Packer) 打包 → _img_plist (.webp + .plist)

### 音频使用
- 工程中使用 .bnk 格式调用音频事件
- .mp3 需由音频人员处理后才能在 Redream 中使用

## 六、常见问题 FAQ

| 问题 | 原因/解决 |
|------|-----------|
| 保存后无法撤销 | 保存会清除操作记录，保存前确认无需恢复内容 |
| 导入文件夹后贴图丢失 | 不能直接导入整个项目文件夹，需分别导入子文件夹（ccb、plist等） |
| 父节点尺寸影响子节点显示吗？ | 节点尺寸≠显示尺寸，父节点起"组/盒子"作用，帮助对齐 |
| 调整父子级后排版全乱 | 子节点默认锚点对齐父节点左下角。解决：将子节点坐标改为百分比模式（如 50%,50%） |
| CCB 文件存哪了？ | 创建文件时左侧资源管理器选中的文件夹即为存储位置 |

## 七、粒子系统进阶

### 曲线编辑
- 双击曲线添加关键点
- 右键关键点可删除
- 框选支持多选关键点

### 切线模式
| 模式 | 说明 |
|------|------|
| Auto | 自动设置平滑切线（锁定） |
| Free Smooth | 自由拖动但保持共线平滑 |
| Flat | 水平切线 |
| Broken | 完全自由，可单独设置左右切线 |

### Broken 模式下的切线类型
| 类型 | 说明 |
|------|------|
| Free | 自由拖动 |
| Linear | 指向临近关键点（直线段） |
| Constant | 两关键点间保持常量值 |

### 属性变化模式
| 模式 | 说明 |
|------|------|
| Scalar | 固定值 |
| Two Constants | 两常量定义上下限，随机变化 |
| Curve | 曲线控制随时间变化 |
| Two Curves | 两曲线定义上下限范围 |

### 颜色变化模式
| 模式 | 说明 |
|------|------|
| Color | 固定单色 |
| Random Between Two Colors | 两色间随机插值 |
| Gradient | 渐变 |
| Random Between Two Gradients | 两渐变间随机插值 |
