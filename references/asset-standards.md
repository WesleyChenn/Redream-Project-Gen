## 二、分辨率设置

**必须设置 5 组分辨率**（覆盖 90% 以上手机屏幕）：

| 序号 | 宽 | 高 |
|------|-----|------|
| 1 | 640 | 1136 |
| 2 | 758 | 1136 |
| 3 | 854 | 1136 |
| 4 | 640 | 1388 |
| 5 | 640 | 1430 |

### 相对位置 vs 绝对位置

| 类型 | 定义 | 使用场景 |
|------|------|----------|
| **相对位置** | 元素位置随父节点尺寸动态调整 | 背景、黑色遮罩、需跟随分辨率变化的图标 |
| **绝对位置** | 位置固定，不随父节点/屏幕变化 | 固定位置的元素 |

### 相对尺寸 vs 绝对尺寸

| 类型 | 定义 | 使用场景 |
|------|------|----------|
| **相对尺寸** | 尺寸随父节点/屏幕动态调整 | 背景、黑色遮罩等自适应元素 |
| **绝对尺寸** | 固定数值，不随分辨率改变 | 控件、弹框等 |

## 三、按钮设置规范

- 点击范围 = 按钮**显示大小**，不是按钮图片大小
- 按钮文字需确保**视觉效果**居中
- 默认勾选「按下缩放」，特殊情况取消（如关闭按钮、无按钮功能）

## 四、九宫格精灵图规范

- **目的**：节约美术资源，保证视觉效果，避免拉伸失真
- **对称翻转时注意锚点位置**：避免切图重叠或缝隙
- **绿色进度条不可以用九宫格**

## 五、黑色遮罩透明度

工程内透明度 = 255 × 设计透明度百分比。示例：设计 90% → 工程值 ≈ 230

## 六、公共图片资源管理

### 资源文件夹结构

根目录 `png_plist` 下三大资源文件夹：

| 文件夹 | 对应 .tps 文件 | 用途 |
|---|---|---|
| **模版_通用组件** | 模版_通用组件.tps | 通用 UI 组件（按钮、底板等） |
| **模版_UI** | 模版_UI.tps | 基础 UI 资源 |
| **通用资源_道具** | 通用资源_道具.tps | 道具/奖励物图片 |

**资源隔离规则**：模版_UI_基础、模版_UI_活动、模版_UI_公会 三者互不混用。

### 核心管理规则

1. **资源隔离**：三者严格隔离，禁止跨包引用
2. **基础公共资源范围**：服务于 proj、game、board 三个工程
3. **图片尺寸规则**：多模块复用的图片，出 UI 显示的最大尺寸
4. **非固定尺寸道具**：出 UI 显示的最大尺寸即可

### 命名格式
`大类_子类_具体名称_状态/等级`，中文 + 下划线分隔。

### 固定尺寸道具（432x432）
游戏前道具（common）、游戏内道具（common）、金币奖励物、活动代币、卡包（5 种等级）。

### 通用 UI 组件
- **按钮类**：绿色/蓝色/红色/灰色按钮（大/中/小），关闭按钮，详情按钮
- **底板类**：弹窗底板（大/中/小），信息/文本/反馈文本底板
- **提示点 UI**：红底感叹号/数字，绿色加号，道具数量角标

## 七、美术组标准开发管线

### 自研/复杂项目（三条并行工作流）

- **上线**（中级工程美术）：工程结构说明文档 → Rebolt 工程 → Rebolt 接口文档 → 交付开发
- **中线**（初级工程美术）：交互原型切图 → 美术原型工程 → UI 终稿切图 → 最终换图工程
- **下线**（设计师）：交互设计图 → UI 设计图

### 复刻/简单项目

与自研项目类似，但中级工程美术直接做交互拆解图，UI 设计师独立完成。

### 角色职责

| 角色 | 职责 |
|------|------|
| 交互设计师 | 交互设计图 |
| UI 设计师 | UI 设计图 |
| 中级工程美术 | 工程结构说明文档、Rebolt 工程、Rebolt 接口文档 |
| 初级工程美术 | 切图、美术原型工程、最终换图工程 |

## 八、音效添加规范

### 音效三大分类

1. **操作反馈音效**：确认操作被系统识别（按钮点击、物品放置）。全屏点击关闭时**不添加**。
2. **状态反馈音效**：帮助玩家理解当前情况（进度变化、对象出现/飞行/收集、按钮状态变化、升级）。**只添加到有动画的时间线上**（飞行除外）。
3. **环境反馈音效**：营造环境氛围（背景音）。

### 同步播放事件处理

同一场景中仅为「视觉事件」添加音效，省略非视觉事件音效。防止「声音堆叠」和听觉疲劳。
