# 项目文件夹命名规范

适用范围：各个项目目录下的文件夹

## 文件夹分类规则

- **`_XXX` 前缀文件夹** — 上线需要直接用到的文件（或需要打包进上线包体的文件）
- **无前缀文件夹** — 源文件，不直接上线使用

## 上线文件夹（`_` 前缀）

| 文件夹命名 | 存放内容 |
|-----------|---------|
| `_ccbi` | ccb 文件的导出文件 |
| `_config` | 工程文件（json 文件、多语言文件等） |
| `_font` | 工程直接调用的字体文件（格式为 png、fnt） |
| `_img_single` | 单独存放大图（此文件夹内的图片直接调用，不打包为图集） |
| `_img_plist` | 散图打包成的整图文件，ccb 工程从这里调用图片路径（**禁止从散图文件直接调用**） |
| `_spine` | spine 动画文件的导出二进制文件（**需要将 png 处理成 webp**） |
| `_sound` | 打包成整体的 wise 音频文件，ccb 工程从这里调用音频文件 |
| `_sound_XXX` | 工程直接调用的单个音频文件，XXX 代表音频格式（如 `_sound_mp3`、`_sound_ogg`） |
| `_language` | 多语言文件 |

## 源文件夹（无前缀）

| 文件夹命名 | 存放内容 |
|-----------|---------|
| `ccb` | red 文件（工程文件）、rebolt 文件（附着在 red 文件上且受程序控制）、anim 文件（控制动画速率，不控制动画坐标） |
| `font` | 字体文件的源文件 |
| `image` | 散图文件，美术用到的基础图片资源源文件（**不直接使用**） |
| `tps` | 图集打包源文件 |
| `spine` | spine 动画源文件 |

## 特别说明

1. **`_XXX` 文件夹含义**：所有上线需要直接用到的文件（或需要打包进上线包体里的文件），文件夹命名时前边需要加 `_` 区分，文件夹格式为 `_XXX`。
2. **文件命名统一性**：为了便于管理和区分，尽量保证存放内容文件命名前缀为项目名或者活动名。即格式为 `项目名(活动名)_XXX_XXX`。
3. **image 文件夹中子文件夹设置**：UI 散图需根据图片性质分为 UI 资源和特效资源。命名格式为 `项目名(活动名)_UI资源`、`项目名(活动名)_特效资源`。
