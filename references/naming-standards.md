## PART 01：项目文件夹命名规范

### 带下划线前缀（上线/打包文件）

| 文件夹 | 存放内容 |
|---|---|
| `_ccbi` | ccb 文件的导出文件 |
| `_config` | 工程文件（json、多语言文件等） |
| `_font` | 工程直接调用的字体文件（png、fnt） |
| `_img_single` | 单独大图（直接调用，不打包为图集） |
| `_img_plist` | 散图打包成的整图文件（ccb 从这里调用，**禁止从散图直接调用**） |
| `_spine` | spine 导出的二进制文件（**需将 png 处理成 webp**） |
| `_sound` | 打包成整体的 wise 音频文件 |
| `_sound_XXX` | 单个音频文件，XXX=格式（如 `_sound_mp3`、`_sound_ogg`） |
| `_language` | 多语言文件 |

### 不带下划线前缀（源文件）

| 文件夹 | 存放内容 |
|---|---|
| `ccb` | red 文件（工程文件）、rebolt 文件、anim 文件 |
| `font` | 字体源文件 |
| `image` | 散图源文件（不直接使用） |
| `tps` | 图集打包源文件 |
| `spine` | spine 动画源文件 |

### 特别说明
1. `_XXX` 前缀 = 上线直接用到 / 打包进包体的文件
2. 文件命名前缀统一为 `项目名(活动名)_XXX_XXX`
3. image 子文件夹按图片性质分为 `项目名_UI资源`、`项目名_特效资源`

## PART 02：常见命名术语表

### CCLayer 型 CCB 术语

| 术语 | 说明 |
|---|---|
| **弹窗** | 有黑色遮罩，有弹框形式 |
| **浮层** | 有黑色遮罩，无弹框形式 |
| **全屏反馈** | 无黑色遮罩 |
| **教程界面** | 教程类界面 |
| **活动界面** | 所有活动的主界面统称 |

其他 CCLayer 统称为「界面」。

### Node 型 CCB 术语

| 术语 |
|---|
| 气泡框 |
| 特效 |
| 活动入口 |

### 奖励物 / 收集物 / 兑换物

| 术语 | 定义 |
|---|---|
| **收集物** | 通过玩主游戏获得，有收集物才能参与活动 |
| **兑换物** | 通过参与活动获得，可兑换奖励物 |
| **奖励物** | 道具等，可在主游戏中消耗 |

## PART 03：CCB 文件命名规范

### 常规 CCB 命名格式

| 类型 | 命名格式 | 备注 |
|---|---|---|
| 弹窗 | `项目名_弹窗_弹窗名` | CCLayer |
| 界面 | `项目名_界面_界面名` | CCLayer |
| 浮层 | `项目名_浮层_浮层名` | CCLayer，有遮罩无弹框 |
| 全屏反馈 | `项目名_全屏反馈_反馈描述` | CCLayer |
| 教程界面 | `项目名_教程界面_教程描述` | CCLayer |
| 活动界面 | `项目名_活动界面` | CCLayer |
| 游戏界面 | `项目名_游戏界面` | CCLayer |
| 活动入口 | `项目名_活动入口` | 活动作为单独模块的工程 |
| 特效 | `项目名_特效_特效描述` | |
| 音效接口 | `项目名_音效接口_音效描述` | |
| 资源栏 | `项目名_资源栏` | |
| 通用子级 | `项目名_子ccb描述` | 不同位置使用的子级 |
| 非通用子级 | `项目名_子级ccb描述` | |
| 微级 | `项目名_子级ccb名_微级描述` | 嵌套到子级上的 ccb |

### anim 文件命名

格式：`项目名_飞行速度曲线_详情描述`
示例：`GoodsMerge_飞行速度曲线_兑换物`

### 注意事项
1. **不要重复描述**：正确 `弹珠活动_弹窗_活动开始`，错误 `弹珠活动_弹窗_活动开始弹窗`
2. rebolt 文件命名自动生成，与对应 ccb 一致

## PART 04：单独 CCB 工程搭建规范

### 时间线命名
- 使用下划线分隔：`常态_奖励物`、`动画_获得动画`、`循环动画_已获得`
- **禁止使用**：括号 `()`、空格、`#`、`*`、`=`、拼音

### 图片节点规范
- 图片节点与图片一一对应
- 禁止出现「的副本」字段
- 禁止图片作为父节点使用（不能在图片下嵌套子节点）

### CCB 文件复用
- 复制带 rebolt 的 ccb 必须在工程内操作（右键复制文件）
- **Redream 版本必须一致**（低版本 → 高版本可能出错）

### 程序相关节点标记

| 颜色 | 用途 | 限制 |
|---|---|---|
| 红色 | 程序调用 | 节点不能 K 时间线帧 |
| 黄色 | 程序显隐 | 节点不能 K 可见帧 |
| 蓝色 | 程序赋值 | 文本节点不能 K 文本内容帧 |

## PART 05：图片文件规范

### UI 图片命名
格式：`[项目名]_[模块名]_[类别]_[功能/状态/描述]`

规则：
- 下划线分隔，避免空格和不兼容字符
- 名称简洁可读
- 统一使用中文命名（除下划线外）

### 特效图片命名
格式：`[项目名]_[特效]_[功能/状态/描述]`

### 图片资源整理
- 未引用的图片从文件夹删除
- 复用图片只保留尺寸最大的一份
- 对规则图片进行切图，最小化资源占用
