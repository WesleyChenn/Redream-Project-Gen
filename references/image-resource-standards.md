## 一、资源文件夹结构

根目录 `png_plist` 下三大资源文件夹：

| 文件夹 | 对应 .tps 文件 | 用途 |
|---|---|---|
| **模版_通用组件** | 模版_通用组件.tps | 通用 UI 组件（按钮、底板等） |
| **模版_UI** | 模版_UI.tps | 基础 UI 资源 |
| **通用资源_道具** | 通用资源_道具.tps | 道具/奖励物图片 |

### 模版_UI 子目录（严格隔离）

| 子文件夹 | 适用范围 |
|---|---|
| **模版_UI_基础** | 基础通用资源（proj、game、board 工程） |
| **模版_UI_活动** | 活动相关资源 |
| **模版_UI_公会** | 公会相关资源 |

**资源隔离规则**：三者互不混用，如 game 工程不能引用 模版_UI_活动.plist 的资源。

### 通用资源_道具 子目录

| 子文件夹 | 内容 |
|---|---|
| C0 通用资源 | 通用道具 |
| C1 单物件 | 单个奖励物品 |
| C2 奖励提示 | 奖励提示相关 |
| C3C4 奖励收集 | 奖励收集相关 |
| C5 资源栏 | 资源栏相关 |

## 二、核心管理规则

1. **资源隔离**：模版_UI_基础、模版_UI_活动、模版_UI_公会 三者严格隔离，禁止跨包引用
2. **基础公共资源范围**：服务于 proj、game、board 三个工程
3. **通用组件存放**：除奖励物/道具外，common 中 ccb 使用的图片资源放在「模版_通用组件」
4. **图片尺寸规则**：多模块复用的图片，出 UI 显示的最大尺寸
5. **非固定尺寸道具**：出 UI 显示的最大尺寸即可，节省资源

## 三、命名规范

### 命名格式
`大类_子类_具体名称_状态/等级`，中文 + 下划线分隔。

### 常见命名前缀

| 前缀 | 适用范围 | 示例 |
|---|---|---|
| `通用资源_道具_` | 通用道具图片 | `通用资源_道具_外部道具1` |
| `模版_UI_` | UI 基础资源 | `模版_UI_金币` |
| `OSG_游戏状态模块_` | 游戏状态相关 | `OSG_游戏状态模块_连胜奖励道具_图标_等级1` |
| `道具状态角标_` | 道具状态指示 | `道具状态角标_道具数量` |
