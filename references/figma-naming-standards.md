# Figma 命名规范与控件标准

来源：「Figma 命名规范与控件标准」docx（Echo/叶可 2026-03-19，Elsa+甘比 2026-03-20 更新，工程校准 2026-03-20）

适用范围：手机休闲游戏 UI 低保真原型还原流程
标准分辨率：1080 × 2400px

---

## 一、命名公式

```
[类型前缀_][语义描述]
```

**原则：**
- 类型前缀固定，不可自创
- 全部使用中文（技术关键词除外）
- 语义描述优先使用游戏业务语言（如"血量"而非"progressBar"）

## 二、类型前缀规范

| 前缀 | 对应元素 | 示例 |
|------|--------|------|
| `按钮_` | 可点击按钮（含图标按钮） | 按钮_开始游戏、按钮_关闭 |

## 三、组件状态（Variant）命名

Variant 属性统一命名为 **"状态"**。

| 状态值 | 适用组件 |
|--------|---------|
| 默认 | 按钮、开关、选项卡 |
| 按下 | 按钮 |
| 禁用 | 按钮、输入框 |
| 选中 / 未选中 | 选项卡、列表项 |
| 开 / 关 | 开关 |
| 有道具 / 空 | 道具格 |
| 已解锁 / 未解锁 | 关卡节点、成就图标 |
| 已领取 / 未完成 / 可领取 | 任务列表项、签到格 |
| 冷却中 | 技能按钮、道具格 |

## 四、元素分类规则

AI 分析截图时，必须对每个元素判断以下分类，分类决定 Figma 组件结构：

| 分类 | 说明 | 常见类型 | Figma 结构 |
|------|------|--------|-----------|
| **Static** | 不随操作/状态变化 | 背景、装饰图、分割线、标题文字 | 直接用 Rectangle/Frame/Text，不需 Variant |
| **Interactive** | 响应玩家点击/触摸 | 按钮、开关、输入框、选项卡 | 创建 Component + 多状态 Variant |
| **State-driven** | 随游戏状态变化（非直接操作） | 血量条、道具格、关卡节点 | 创建 Component + Variant |
| **Data-driven** | 承载动态数据，结构固定内容变化 | 道具卡片、排行榜列表项 | 创建 Component 供列表复用 |

## 五、布局约束规范

| 约束类型 | JSON 值 | 含义 |
|---------|--------|------|
| 水平居中 | `"horizontal": "CENTER"` | 相对父容器水平居中 |
| 垂直居中 | `"vertical": "CENTER"` | 相对父容器垂直居中 |
| 顶部固定 | `"vertical": "TOP"` | 固定距顶部边距 |
| 底部固定 | `"vertical": "BOTTOM"` | 固定距底部边距 |
| 左侧固定 | `"horizontal": "LEFT"` | 固定距左侧边距 |
| 右侧固定 | `"horizontal": "RIGHT"` | 固定距右侧边距 |
| 水平拉伸 | `"horizontal": "SCALE"` | 左右两端锁定，随宽度缩放 |
| 垂直拉伸 | `"vertical": "SCALE"` | 上下两端锁定，随高度缩放 |

## 七、补充结构规则

### C-4 覆盖型元素居中规则
Toggle 划线等覆盖型元素必须居中于父级 Frame：
- `slash_x = (parent_w - slash_w) // 2`
- `slash_y = (parent_h - slash_h) // 2`
- 禁止固定 offset（如 x=5），父级尺寸变化后偏离

### C-5 同类视觉层合组规则
阴影+主板必须合组进 `底板组`：
```
按钮组
├── 底板组（阴影RECT + 主板RECT）
│   底板组 尺寸：x=0, y=0, w=按钮w, h=按钮h+12，无 fill
└── 内容组（图标 + 文字）
```

## 八、图片资源完整命名公式

Figma 图层命名遵循「类型_描述」格式。导出为图片资源文件时，需加上项目前缀和模块名：

```
[项目前缀]_[模块名]_[类型前缀]_[语义描述]
```

示例：`FP_订单模块_按钮_关闭.png`、`M8G_棋盘模块_底板_标题底板.png`

## 九、常用命名后缀规范

以下后缀可追加在命名末尾，表示元素的变体或分组关系：

| 后缀 | 用途 | 示例 |
|------|------|------|
| `_左` / `_右` | 对称元素镜像拼合（只出一半贴图，scaleX=-1 镜像），节省 50% 贴图空间 | 底板_弹窗底板_左、底板_弹窗底板_右 |
| `_描边` | 文字描边层，与同名主文本层叠加使用（底层描边偏下 2px + 上层纯白文字） | 文字_标题文本_描边、文字_标题文本 |
| `_数字序号` | 同类重复元素按序编号（_1、_2、_3…） | 插图_花束_1、插图_花束_2 |
| `_颜色` | 同类元素按颜色区分变体（_绿色、_蓝色、_红色…） | 按钮基底_绿色、按钮基底_蓝色 |
| `_状态` | 同类元素按状态区分变体（_满、_空、_ON、_OFF…） | 进度条格_满、进度条格_空 |

## 十、JSON 输出格式

AI 分析截图时输出的 JSON 必须包含以下字段：

```json
{
  "meta": {
    "design_size": { "w": 1080, "h": 2400 },
    "standard_size": { "w": 1080, "h": 2400 }
  },
  "screens": [{
    "id": "screen_唯一标识",
    "name": "界面_页面名称",
    "width": 1080,
    "height": 2400,
    "layers": [{
      "name": "类型前缀_语义描述",
      "type": "FRAME | RECTANGLE | TEXT",
      "element_class": "static | interactive | state_driven | data_driven",
      "x": 0, "y": 0, "w": 0, "h": 0,
      "fill": "#RRGGBB",
      "corner_radius": 0,
      "constraints": {
        "horizontal": "LEFT | CENTER | RIGHT | SCALE",
        "vertical": "TOP | CENTER | BOTTOM | SCALE"
      },
      "font_size": 28,
      "font_weight": "Regular | Bold",
      "content": "文字内容（TEXT类型）",
      "children": [],
      "label": {
        "content": "按钮文字",
        "font_size": 28,
        "font_weight": "Bold",
        "color": "#FFFFFF"
      }
    }]
  }]
}
```
