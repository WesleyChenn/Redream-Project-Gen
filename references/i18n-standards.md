# 字体与多语言规范

来源：字体资源规范.pdf + 多语言文本配置需求文档_redream翻译.pdf

---

## 一、字体资源核心理念

将**字体样式**和**字体本身**分开输出，在工程内上下叠加实现多种视觉效果：
- 纯色字体 → 输出纯白色字体，工程内调色
- 渐变色字体 → 输出灰色渐变层，工程内调色
- 描边/其他样式 → 输出纯白色样式字体，工程内调色

---

## 二、字体资源制作

### 字号标准
- **标准字号：100**（满足大部分字体需求，特殊情况另作处理）

### 字体和样式制作

#### 纯色字体 + 描边样式
1. 制作纯色字体时，给字体加**透明度 0% 的描边**占位
2. 制作描边样式资源：字号 50 的纯白色字体 + 纯白色描边
3. 输出：字体纯白色（描边透明度 0%） + 纯白色样式字体资源

#### 渐变字体
1. 字体加透明度 0% 的描边占位
2. 输出：纯色字体（纯白+透明描边）+ 渐变字体（灰色渐变+透明描边）+ 纯白色样式

**关键规则**：描边样式的描边尺寸与字体 0% 透明度描边尺寸**必须完全相同**

### 字体资源输出
- **最终输出格式**：webp
- **命名格式**：`项目名称_字体/字体样式_具体描述`
- .fnt 文件中需将 `png` 改为 `webp`

## 三、字体应用（工程内）

以弹窗标题为例：
1. 在标题组新建「标题文本」node
2. 先放「文本样式」：坐标 **50%, 50%**，对齐 **左右居中, 上下居中**
3. 再放「文本」：坐标 **50%, 50%**，对齐 **左右居中, 上下居中**

**调整位置/大小时**：调整上层 node，不要动里面的内容

### 字体检查清单
- [ ] 字体和字体样式各属性数值是否一致？
- [ ] 描边数值是否一致？
- [ ] 所有字体是否在同一个文本 node 内？
- [ ] 坐标是否设为 50% 50%？
- [ ] 对齐方式是否为上下居中、左右居中？

## 四、多语言文本配置

### 配置范围
- **需要配置**：除数字、游戏术语及特定标签外，所有工程文字
- **不需要配置**：纯数字、游戏术语、特定标签

### Key 命名规范

格式：`keyN_[文本功能]_[文本内容]`

| 类别 | 示例 |
|------|------|
| 按钮文本 | `key1_按钮文本_开始` |
| 提示文本 | `key2_提示文本_网络未连接文本` |
| 标题文本 | `key3_标题文本_活动标题` |
| 反馈文本 | `key4_反馈文本_你赢啦` |
| 详情文本 | `key5_详情文本_规则说明` |

**命名注意**：不能有空格

### 多语言文件
- 后缀为 `.lan`
- **必须放在 `_language` 文件夹下**

## 五、字体样式设置

### 语系管理
- 按语系分组管理，拉丁语为通用语言
- 字体资源位置：工程内 `_fonts` 文件夹

### 字体样式设置步骤
1. 点击「语言设置」→ 选取需要的语言
2. 将 `_font` 文件夹导入到工程
3. 设置字体样式（命名需和字体命名有对应关系）

### 注意事项
- **必须开启多语言**才能设置字体样式
- 标点符号不能用中文字符（会导致 UI 显示不能居中）

## 六、变量文本翻译

### 使用场景
- 多语言文本需要程序传数值（如卡片数量）
- 3 个或以上文本一致，只有数值/特定内容不同

### 变量代号
`#!1`、`#!2`、`#!3`、`#!4`（每段文本最多支持 4 个变量）

在 Rebolt 中进行变量配置。
