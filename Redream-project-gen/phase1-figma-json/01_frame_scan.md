# S1 · 全帧扫描【录屏专用】

> 开始前先读取 `00_core_rules.md`

---

## 输入

用户提供的 .mp4/.mov 录屏文件。

## 执行

1. **提取帧**：PyObjC + AVFoundation 提取 3fps（每333ms一帧）

2. **逐帧查看全部帧，不得跳过**，记录每帧界面状态

3. **触摸点识别（强制执行，不得跳过）**

   对**每一帧**执行以下两步：

   **3-1. 像素扫描**：搜索半透明白色圆形区域，判定条件：
   - RGB 均值 > 200，且与周围像素亮度差 > 40
   - 直径范围 20–60px（源帧像素）
   - 记录圆心坐标 (x, y)

   **3-2. 映射 UI 元素**：将触摸点坐标映射到当前帧可见的 UI 层级，确认被点击的具体节点名称。特别注意：
   - 触摸点落在**场景背景/建筑/地图区域**时，视为点击该区域对应的隐式交互目标，必须记录（不得因"不是明显按钮"而忽略）
   - 触摸点不可见时（录屏未开启触摸显示），标注「来源未确认」，不得省略该帧的转场记录

4. **汇总屏幕清单**：帧差分 >40% → 独立屏幕；仅遮罩变暗不算独立屏幕

5. **转场回溯（强制，每次帧差分 >40% 后立即执行）**

   发现转场时，必须回溯**前 3 帧**：
   - 找到触摸点坐标 → 确认触发元素 → 记入交互连线
   - 找不到触摸点 → 标注「来源未确认」，仍然记录该转场，不得省略
   - **禁止**：仅记录新屏幕而不追溯是谁触发了跳转

6. **识别翻页类型**（每次画面切换同步判断）：

| 识别特征 | 切换类型 | 动画 |
|---|---|---|
| 过渡帧中两屏同时可见，内容横向位移，导航栏不动 | Tab 导航切换 | `slide 300ms` |
| 触摸点在内容区按钮，切换后结构完全不同 | 全屏页面跳转 | `dissolve 300ms` |
| 原屏幕变暗仍可见，新内容浮在上方 | 弹窗/浮层打开 | `dissolve 300ms` (OVERLAY) |
| 触摸点在浮层关闭按钮，回到原屏幕 | 浮层关闭 | CLOSE |
| 底部 Nav 高亮 Tab 变化 | 推断为 Tab 切换 | `slide 300ms` |
| 触摸点落在场景背景/建筑物上，切换后结构完全不同 | 全屏页面跳转 | `dissolve 300ms` |

7. **屏幕类型判断**：
   - 全屏替换 → `界面_` 前缀
   - 弹窗覆盖（原画面变暗可见）→ `浮层_` 前缀
   - 活动页面占满全屏 → `界面_`，不是 `浮层_`

## 触摸点不可见时的兜底规则

录屏时若系统未开启触摸显示（Settings → Developer Options → Show taps），触摸点将不可见。此时：

1. 对帧差分 >40% 的每次转场，回溯前 3 帧，观察画面焦点变化区域推断触发元素
2. 标注「来源未确认」并列出最可能的候选触发元素（1–3个）
3. 仍然完整记录该转场，不得因来源不明而省略交互连线
4. **建议**：告知用户下次录屏前开启触摸点显示，以提升识别准确率

## 输出格式

```
共 N 帧，识别到 M 个独立屏幕：
1. 界面_主地图（0-3s）
2. 界面_xxx（3-7s）
3. ...

识别到 K 条交互连线：
1. 界面_A → 界面_B（dissolve 300ms，触摸点@(x,y)→按钮_xxx）
2. 界面_A → 浮层_C（dissolve 300ms OVERLAY，触摸点@(x,y)→组_xxx）
3. 浮层_C → 界面_A（CLOSE，触摸点@(x,y)→组_关闭按钮）
4. 界面_A → 界面_D（dissolve 300ms，来源未确认，候选：背景_地图场景 / 按钮_xxx）
```

## 禁止

- 看前几帧就开始输出 JSON
- 跳帧
- 未确认清单就进入下一步
- 发现转场但不回溯触摸点来源
- 因触摸点不可见而省略整条交互连线
