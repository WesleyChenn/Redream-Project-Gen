## 一、命名公式

```
[类型前缀_][语义描述]
```

- 类型前缀固定，**不可自创**
- 全部使用中文（技术关键词除外）
- 语义描述优先使用游戏业务语言（如"血量"而非"progressBar"）

---

## 二、顶层 Frame 前缀（按模态区分）

| 前缀 | 含义 | 示例 |
|---|---|---|
| `界面_` | 主功能界面（全屏独立页面） | `界面_设置`、`界面_主页` |
| `弹窗_` | 弹窗/模态框（有全屏遮罩） | `弹窗_开启通知`、`弹窗_退出确认` |
| `浮层_` | 浮层/气泡（无遮罩浮动内容） | `浮层_Toast`、`浮层_操作菜单` |

**废弃：** `屏幕_xxx` ← 不表达模态语义，禁止使用。

## 四、element_class 取值

AI 分析截图时，每个元素必须判断以下分类，分类决定 Figma 组件结构：

| 值 | 含义 | 常见类型 | 是否需要 Component+Variant |
|---|---|---|---|
| `static` | 静态元素，不随任何操作/状态变化 | 背景、装饰图、分割线、标题文字、说明文字 | ❌ 不需要 |
| `interactive` | 响应玩家点击/触摸 | 按钮、开关、输入框、选项卡 | ✅ 需要 Component |
| `state_driven` | 随游戏状态变化（非玩家直接操作） | 血量条满/半/空、道具格有/空、关卡节点解锁/锁定 | ✅ 需要 Component+Variant |
| `data_driven` | 承载动态数据，结构固定但内容变化 | 道具卡片、排行榜列表项、任务列表项 | ✅ Component 供列表复用 |

## 五、组件状态（Variant）命名

所有交互组件必须明确标注状态，Variant 属性统一命名为"状态"：

| 状态值 | 适用组件 |
|---|---|
| 默认 | 按钮、开关、选项卡 |
| 按下 | 按钮 |
| 禁用 | 按钮、输入框 |
| 选中 | 选项卡、列表项、道具格 |
| 未选中 | 选项卡、列表项 |
| 开 / 关 | 开关 |
| 有道具 / 空 | 道具格 |
| 已解锁 / 未解锁 | 关卡节点、成就图标 |
| 已领取 / 未完成 / 可领取 | 任务列表项、签到格 |
| 冷却中 | 技能按钮、道具格 |

## 六、命名后缀规范

可追加在命名末尾表示变体或分组关系：

| 后缀格式 | 含义 | 示例 |
|---|---|---|
| `_状态` | 同类元素按状态区分变体 | `进度条格_满`、`进度条格_空` |
| `_颜色` | 同类元素按颜色区分变体 | `按钮基底_绿色`、`按钮基底_蓝色` |
| `_数字序号` | 同类重复元素按序编号 | `插图_花束_1`、`插图_花束_2` |
| `_描边` | 文字描边层（底层描边偏下2px + 上层纯白文字）| `文字_标题文本_描边`、`文字_标题文本` |
| `_左` / `_右` | 对称元素镜像拼合（scaleX=-1 镜像节省贴图） | `底板_弹窗底板_左`、`底板_弹窗底板_右` |

## 七、图片资源完整命名公式（导出用）

```
[项目前缀]_[模块名]_[类型前缀]_[语义描述]
```

示例：`FP_订单模块_按钮_关闭.png`、`M8G_棋盘模块_底板_标题底板.png`

## 八、布局约束规范

> **Figma Plugin API 枚举值：** `MIN`=贴顶/贴左，`MAX`=贴底/贴右，`CENTER`=居中，`SCALE`=拉伸。
> API **不接受** `TOP`/`BOTTOM`/`LEFT`/`RIGHT`。

| 约束类型 | Figma API 值 | 含义 |
|---|---|---|
| 水平居中 | `horizontal: "CENTER"` | 相对父容器水平居中 |
| 垂直居中 | `vertical: "CENTER"` | 相对父容器垂直居中 |
| 顶部固定 | `vertical: "MIN"` | 固定距顶部边距 |
| 底部固定 | `vertical: "MAX"` | 固定距底部边距 |
| 左侧固定 | `horizontal: "MIN"` | 固定距左侧边距 |
| 右侧固定 | `horizontal: "MAX"` | 固定距右侧边距 |
| 水平拉伸 | `horizontal: "SCALE"` | 左右两端锁定，随宽度缩放 |
| 垂直拉伸 | `vertical: "SCALE"` | 上下两端锁定，随高度缩放 |

## 九、弹窗遮罩命名

> **废弃旧名称 `全屏遮罩`**，统一使用 `遮罩_` 前缀：

| 旧名称 | 新命名 | 场景 |
|---|---|---|
| `全屏遮罩` | `遮罩_弹窗` | 弹窗半透明黑色背景 |
| _(无)_ | `遮罩_黑色` | CCLayerColor 全屏黑色遮罩 |
| _(无)_ | `遮罩_锁定` | 关卡节点锁定遮罩 |

## 十、常用控件命名速查（六大场景）

### 6.1 游戏内 HUD
`进度条_血量`、`进度条_体力`、`文字_金币数量`、`文字_倒计时`、`按钮_暂停`、`列表项_道具格`、`按钮_技能`

### 6.2 主界面 / 大厅
`面板_顶部资源栏`、`图片_玩家头像`、`标签_等级`、`进度条_经验`、`按钮_开始游戏`、`面板_底部导航栏`、`列表项_导航项`、`标签_消息红点`

### 6.3 关卡选择
`列表项_关卡节点`（已解锁/锁定/当前）、`图片_星级`、`遮罩_锁定`、`文字_章节名称`

### 6.4 结算界面
`插图_胜利`、`插图_失败`、`图片_结算星级`、`列表_奖励`、`列表项_奖励`、`按钮_再来一次`、`按钮_返回主界面`、`按钮_广告复活`

### 6.5 弹窗系统
`遮罩_弹窗`（半透明黑背景）、`弹窗_[功能名]`（圆角面板）、`文字_弹窗标题`、`按钮_关闭`、`按钮_确认`、`按钮_取消`、`底板_弹窗底板`、`底板_标题底板`、`面板_标题栏`

### 6.6 商店
`列表项_商品卡片`（图标+名称+价格）、`文字_商品价格`、`标签_折扣`、`标签_限时`、`按钮_购买`、`列表项_充值档位`

### 6.7 设置 / 功能区
`开关_音效`、`开关_振动`、`滑块_音量`、`列表项_设置项`
