# 标准工程模式（从实际项目案例提炼）

来源：6 个标准工程样例（CrossMatch、FlowerGroup、FoodPuzzle、JuiceBar、PerfectCooking、Unravelyarn）

---

## 一、项目架构模式

### 1.1 多工程分层架构

| 工程类型 | 前缀 | 职责 | 示例 |
|---------|------|------|------|
| **common** | `res_模板公用` | 跨项目复用的通用组件（C1~C5系列）、字体、图集 | res_flower_common |
| **proj** | `M8P_` | 项目特有的主页、商店、设置等 UI 模块 | res_flower_proj |
| **game** | `OSG_` | 游戏上层 UI、订单系统、弹窗、角色表现 | res_foodpuzzle_game |
| **board** | `M8G_` | 棋盘核心玩法、元素节点、道具特效 | res_foodpuzzle_board |
| **engine** | 项目缩写 | 游戏引擎逻辑（较小型项目） | resmathgameengine |

### 1.2 工程间引用方式
- proj 通过 `../res_xxx_common/` 相对路径引用 common 资源
- game 通过 `../res_xxx_board/` 引用 board 的图片资源
- **核心原则**：game = "壳"（UI/流程），board = "核"（核心玩法）

## 二、节点命名规范（实际案例）

### 2.1 文件命名格式
`项目前缀_模块名_类型_具体名称.red`

| 项目 | 前缀 | 示例 |
|------|------|------|
| CrossMatch | CM_ | CM_主游戏模块_界面_游戏界面.red |
| FlowerGroup | M8P_/FGP_ | M8P_体力模块_弹窗_更多生命.red |
| FoodPuzzle | FP_/M8G_ | FP_订单模块_弹窗_订单超时.red |

### 2.2 节点命名规律
| 节点类型 | 标准命名 |
|---------|---------|
| CCNode（容器） | 背景组、安全区域、总组、按钮组、信息栏、标题栏、弹窗总组 |
| REDNodeButton | 全屏点击屏蔽、全屏防穿透按钮、全屏退出按钮、关闭按钮 |
| CCLayerColor | 黑色遮罩 |
| RedSafeAreaLayer | 安全区域、UI安全区域节点 |
| CCScale9Sprite | 底板、弹窗底板、气泡框 |
| CCSprite | 背景图、插图、图标 |
| CCRedLabel/CCLabelPlus | 标题文本、提醒文本、描述文本 |
| REDFile | 按钮组、金币栏、生命栏 |

### 2.3 定位点命名
空 CCNode 作为程序挂载锚点：`xxx定位点`
- banner定位点、弹窗层定位点、角色定位点_单人_任意、节点收集定位点

## 三、层级结构标准模式

### 3.1 界面（CCLayer）标准结构

```
CCLayer (根节点, 100%x100%)
├─ 背景组 (CCNode)
│   ├─ 全屏点击屏蔽 (REDNodeButton, 100%x100%, swallowTouches=true)
│   └─ 背景图 (CCSprite/CCLayerColor)
├─ 安全区域 (RedSafeAreaLayer)
│   └─ 总组 (CCNode, 50%/50%, 100%/100%)
│       ├─ 顶部UI栏 (CCNode)
│       │   ├─ 资源栏 (REDFile引用)
│       │   └─ 按钮组 (CCNode)
│       └─ 内容区域 (CCNode)
├─ banner定位点 (CCNode)           ← 广告位
└─ 弹窗层定位点 (CCNode)           ← 弹窗挂载
```

### 3.2 弹窗标准结构

```
CCLayer (根节点)
├─ 总组 (CCNode, visible=false)     ← 初始隐藏，由动画控制显示
│   ├─ 全屏防穿透按钮 (REDNodeButton, 100%x100%)
│   ├─ 黑色遮罩 (CCLayerColor, opacity=170~204, color=[0,0,0])
│   └─ RedSafeAreaLayer
│       └─ 弹窗总组 (CCNode)
│           ├─ 弹窗底板 (CCScale9Sprite)
│           ├─ 标题栏 (CCNode)
│           │   ├─ 标题底板 (CCSprite)
│           │   ├─ 标题文本_描边 (CCRedLabel)  ← 描边层
│           │   ├─ 标题文本 (CCRedLabel)        ← 主文本层
│           │   └─ 关闭按钮 (REDNodeButton)
│           ├─ 内容区域 (CCNode)
│           └─ 按钮组 (CCNode)
│               ├─ 按钮_确认 (REDNodeButton)
│               └─ 按钮_取消 (REDNodeButton)
└─ 浮层定位层 (CCNode)
```

### 3.3 浮层标准结构

```
CCLayer (根节点)
├─ 背景组 (CCNode)
│   ├─ 全屏点击层 (REDNodeButton)
│   └─ 背景图 (CCSprite)            ← 全屏背景图（非半透明遮罩）
├─ 总组 (CCNode)
│   └─ 信息组 / 结算组
└─ 底部按钮组 (CCNode)
```

**弹窗 vs 浮层区别**：弹窗用半透明黑色遮罩，浮层用完整背景图覆盖全屏。

## 四、视觉技巧

### 4.1 左右镜像拼合
底板和装饰元素只出一半贴图，通过 `scaleX=-1` 镜像拼合，**节省 50% 贴图空间**：
```
弹窗底板_左 (CCSprite)                  ← 原图
弹窗底板_右 (CCSprite, scaleX=-1)       ← 镜像
```
花束、绳子、侧板等对称元素同理。

### 4.2 文本描边双层法
两个 CCRedLabel 垂直偏移 2px 叠加：
```
标题文本_描边 (CCRedLabel, 描边字体, 偏下2px)   ← 底层描边/阴影
标题文本 (CCRedLabel, 纯白字体)                  ← 上层主文本
```

### 4.3 黑色遮罩透明度
| 场景 | opacity 值 | 百分比 |
|------|-----------|--------|
| 弹窗标准 | 170~204 | 67%~80% |
| 体力弹窗 | 180 | 70% |
| 订单超时弹窗 | 204 | 80% |

### 4.4 按钮音效标准配置
- 关闭按钮：`wiseOnTouchUpInside = "UI_popup_close"` (res_common.bnk)
- 普通按钮：`wiseOnTouchUpInside = "UI_btn"` (res_common.bnk)
- 按下缩放：`scaleRatio = 0.9`（默认开启）

## 五、时间线标准模式

### 5.1 命名规范

| 命名格式 | 含义 | 时长范围 |
|---------|------|---------|
| `常态` | 默认显示状态 | 0.03s（瞬时） |
| `常态_xxx` | 条件性默认状态 | 0.03s |
| `动画_进入` / `进入动画` | 弹窗/界面进入 | 0.33s ~ 2.0s |
| `动画_退出` / `退出动画` | 弹窗/界面退出 | 0.03s ~ 0.33s |
| `动画_步骤N_xxx` | 分步引导动画 | 1.0s ~ 2.5s |
| `动画_xxx反馈` | 反馈动画 | 0.3s ~ 1.0s |

### 5.2 进入动画标准模式
```
t=0:       总组 visible=true
t=0~0.133s: 黑色遮罩 opacity 0→204（线性淡入）
t=0~0.5s:   弹窗总组 scale 0.6→1.0 + opacity 0→255（ElasticOut 弹性）
t=0~0.7s:   子内容延迟出现（scale 0→1）
```

### 5.3 退出动画标准模式
- 时长极短（0.03s~0.07s）
- 直接将 opacity 和 scale 清零（瞬间消失）

### 5.4 chain 规则
- `chain: -1` = 不自动链式播放（默认）
- `chain: N` = 播完后自动播第 N 条时间线（用于循环动画，指向自身）

## 六、Rebolt 逻辑标准模式

### 6.1 必备函数

**每个 .rebolt 都必须有**：

| 函数名 | 作用 |
|--------|------|
| `初始化` | 绑定子组件节点、通知工程师绑定节点 |
| `更新` / `刷新UI` | 数据更新后刷新 UI 显示 |

**常见附加函数**：

| 函数名 | 作用 |
|--------|------|
| `启用按钮` / `禁用按钮` | 批量控制按钮交互性 |
| `退出` / `弹窗退出` | 播放退出动画 |
| `设置程序节点` / `绑定节点` | 将定位点传递给程序 |

### 6.2 变量命名规范

| 前缀 | 含义 | 示例 |
|------|------|------|
| `P-` | 程序变量（由程序端传入） | P-图标plist, P-奖励数量, P-类型, P-倒计时文本 |
| 无前缀 | 自定义变量（内部使用） | 声音按钮状态, 动画序号 |

**数据流向**：程序设置 P- 变量 → 调用「更新」函数 → Rebolt 读取变量并设置 UI

### 6.3 按钮点击标准流程

```
按钮被点击 (BTButtonClickFuncAction)
  → 禁用按钮 (BTButtonEnableAction / BTCustomFuncBodyAction)
  → 通知工程师 (BTNotificationToCoderAction, msg="xxx被点击")
  → 播放退出动画 + 回调 (BTPlayTimeLineActionWithCallBack)
       → 回调: 通知工程师 (msg="退出动画播完")
  → 等待 (BTWaitTimeAction)
  → 启用按钮
```

### 6.4 初始化绑定节点模式

```
初始化函数 (BTCustomFuncHeadAction):
  → 通知工程师_Node (msg="绑定节点", node=定位点1)
  → 通知工程师_Node (msg="绑定节点", node=定位点2)
  → 通知工程师_Node (msg="绑定节点", node=定位点3)
  → ... (链式绑定所有定位点)
```

### 6.5 条件分支更新模式

```
更新函数:
  IF P-类型 == "普通奖励":
    设置文本、设置精灵图、播放时间线"普通奖励"
  ELSE IF P-类型 == "限时奖励":
    设置文本、设置精灵图、播放时间线"限时奖励"
  ELSE:
    设置文本、设置精灵图、播放时间线"金币奖励"
```

### 6.6 回调链模式（异步动画串联）

```
函数A:
  播放时间线"出现" + 回调B

回调B:
  通知工程师"出现动画播完"
  播放时间线"消除" + 回调C

回调C:
  通知工程师"消除动画播完"
```

### 6.7 测试函数标准

每个 .rebolt **必须有** `BTTestFuncAction`：
```
测试函数:
  设置 P- 变量的测试值
  调用 初始化()
  调用 更新()
```

### 6.8 通知工程师消息命名规范

| 格式 | 示例 |
|------|------|
| `xxx被点击` | "确认按钮被点击"、"关闭按钮被点击"、"容易难度被点击" |
| `xxx动画播完` | "退出动画播完"、"道具出现动画播完" |
| `绑定节点` | "绑定节点"（配合 Node 参数） |

## 八、多语言标准配置

### 字体组合（6~7 种语言）
拉丁语、俄语、日语、繁体中文、阿拉伯语、韩语（+ 符号字体）

### 每种语言 x 字重（Bold/Medium）x 样式
- 纯白字体 (.fnt + .webp)
- 描边字体 (.fnt + .webp)
- 渐变字体（可选）

### 多语言切换
文本节点通过 `fontI18n` / `localizationV2` 属性实现自动语言切换。
