# 浮层_活动入口 pattern

游戏内"活动入口弹窗"的高频 layout — 玩家点活动按钮后跳出这个弹窗看详情。**整屏或大半屏**, 固定结构。

## 5 维特征

| 维度 | 规律 |
|---|---|
| 形状 | 全屏 / 大半屏 FRAME(移动端常 1080×2400 / 1170×2532)|
| 构成 | 必有 5 区:**顶左 i** / **顶右 X** / **中央装饰** / **活动标题** / **底部倒计时** + 可选副标题 |
| 位置 | 固定布局(见下结构图)|
| 量级 | 整屏级(>1000px 宽 / >2000px 高)|
| 底板 | 整屏背景(花纹 / 纯色 / 装饰背景)|

## 标准结构图

```
浮层_活动入口_<语义> (FRAME 全屏, 1170×2532)
├── 背景区(0~2532, NONE 父)
│   ├── 图片_背景_装饰 (RECT 全屏占位, 数据驱动 — 场景特定花纹)
│   └── 装饰边框/塔楼/帐篷等(可选, RECT 占位)
│
├── 顶部按钮区(0~150)
│   ├── 按钮_信息 (component_ref 圆形按钮_信息, 左上 LEFT/TOP)
│   └── 按钮_关闭 (component_ref 圆形按钮_关闭, 右上 RIGHT/TOP)
│
├── 中央装饰主图区(150~1700)
│   ├── 图片_装饰_主场景 (RECT 大占位, 数据驱动)
│   │   ← 可包含: 靶/人物/颁奖台/装饰元素(都是 RECT 占位, 不拆 Component)
│
├── 活动标题区(1700~2000)
│   ├── 底板_标题 (RECT, 圆角矩形, 米黄/亮色)
│   └── 文本_活动标题 (TEXT, 大字, 粗体+描边, 居中)
│
├── 底部倒计时区(2000~2200)
│   └── 倒计时 (component_ref 底标_倒计时, **底部正中央** narrow 底标)
│       ⚠️ narrow 底标定义(2026-05-12 用户教学):
│         · 位置:**浮层底部正中央**(不是任意位置)
│         · 内容:**倒计时**(钟表+时间)
│         · 视觉:左钟表 + 右底板+文本(=横排徽章钟表变体)
│
└── (可选) 副标题区(2200~2400)
    └── 文本_副标题 (TEXT, 多行说明文字)
```

## 各元素 → 已有 pattern 映射

| 区 | pattern 复用 |
|---|---|
| 顶左 i 按钮 | `单图标_无角标` 按钮型 = 库 `圆形按钮_信息` |
| 顶右 X 按钮 | `单图标_无角标` 按钮型 = 库 `圆形按钮_关闭` |
| 中央装饰 | **占位 RECT 数据驱动**(新 skill 07d 占位 RECT 规则, 不拆 Component, 不抽 Variant)|
| 活动标题 | 简单 `底板 RECT + 文本 TEXT` (可后续抽 `标题胶囊_纯文本` pattern) |
| 倒计时 | `横排徽章_左图右文` = 库 `底标_倒计时` |
| 副标题(可选) | 纯 TEXT 直接 |

## 识别信号(≥4 命中即匹配)

- [ ] 是**全屏/大半屏**(不是行/卡片/小元素)
- [ ] 顶部**两个圆按钮**(左 i + 右 X, 标志性组合)
- [ ] 中央有**大型装饰主图**(占屏幕 40%+ 区域)
- [ ] 底部有**倒计时**(几乎必有)
- [ ] 有**活动名标题**(单行大字)

## Component 命名

```
浮层名: 浮层_<活动名英文/拼音>  (例: 浮层_ArcheryArena / 浮层_LightningRush / 浮层_SkyRace)

内部元素命名:
- 图片_背景_<活动名>
- 图片_装饰_<活动名>_主场景
- 按钮_信息 (component_ref)
- 按钮_关闭 (component_ref)
- 底板_标题
- 文本_活动标题
- 倒计时 (component_ref 底标_倒计时, override 文本_时间)
- 文本_副标题 (可选)
```

## 整体不抽 Component

按新 skill S6 #4 Step B "抽到最小变化粒度" + S11 抽取范围:
- 整个浮层是 **FRAME 包装层**, 不抽 Component
- 内部所有元素是它的 children (扁平 FRAME)
- 不同活动的浮层(Archery/Lightning/Sky)是**不同 screen instances**, 共享同 layout 不共享 Component

## 反面案例

| 看着像但不是 | 区别 |
|---|---|
| 主屏 HUD | HUD 是顶部固定栏, 不是弹窗;含金币/生命栏 |
| 关卡详情弹窗 | 弹窗大小近似但内容不同(关卡星数/解锁条件/奖励列表)|
| 商店 / 道具弹窗 | 含商品列表 + 价格, 不是单一活动入口 |
| 设置弹窗 | 含选项列表, 不是装饰图 + 活动标题 |
