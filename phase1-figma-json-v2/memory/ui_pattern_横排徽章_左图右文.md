# 横排徽章_左图右文_带底板

**典型用途**:状态/资源/进度显示(顶部状态栏、活动入口卡侧栏、列表行右侧统计项)

## 5 维特征

| 维度 | 规律 |
|---|---|
| 形状 | 圆角矩形/胶囊底板 + 左侧独立 icon |
| 构成 | 3 图层: `图标_X` + `底板_X` + `文本_X` |
| 位置 | icon 在左, 底板+文本在右;**icon 上下溢出底板**(icon h > 底板 h);icon 左端与底板可能少量重叠或紧贴 |
| 量级 | 底板长宽比 **2:1 ~ 4:1**(短款到长款都有); icon 正方形, **h = 底板 h × 1.2~1.6** |
| 底板 | 大圆角, `corner_radius ≥ h/3`(短款看起来圆方, 长款看起来胶囊)|
| 颜色 | 底板色谱广:米黄 / 绿 / 紫 / 橙 / 红 / 黄 都见过 — **跨游戏跨场景通用,本规则不依赖颜色** |

## ⚠️ Variant 维度(2026-05-12 用户教学修正)

**横排徽章一般情况下没有 Variant** — 整个界面所有横排徽章视觉结构都统一, 差异在 icon + 数字, 都是数据驱动 + dynamic 文本。

- icon 内容(金币/盾牌/钟表/星星) → **数据驱动**, 占位 RECT, 不是 Variant
- 文本内容(数字/时间/进度/排名) → **dynamic 文本**, 直接写在每个扁平 FRAME 的 TEXT.content, S11 自动收集到 overrides
- 底板色(米黄/绿/紫) → **上下文/场景决定**, 占位 fill, 不是 Variant

**S7 阶段一写法**: 每个徽章实例都画完整扁平 FRAME (底板 + 占位 icon + 文本), TEXT.content 直接写视频里的实际数字。 S11 抽取自动出一个 Component (常态 Variant), TEXT 差异变 INSTANCE.overrides。

⚠️ **以实际视频为准**:如果视频里**同位置的横排徽章出现真状态切换**(例:正常 vs 警告变红), S7 每个实例画完整 FRAME, fill 视觉不同, S11 自动切多个 Variant。 不要凭"可能未来需要"预先做。

## 识别信号(看截图判断时,≥3 条命中即匹配)

- [ ] 有圆角矩形/胶囊底板(`corner_radius ≥ h/3`)
- [ ] icon 在**左外侧**(完全或部分溢出底板左端)
- [ ] icon 高度 **> 底板高度**(上下溢出底板)
- [ ] 文本是**数字 / 时间 / 进度 x/y 格式**(总之是定长字符)
- [ ] 文本颜色与底板色**强对比**(深字浅底 或 浅字深底)
- [ ] 底板长宽比 **2:1 ~ 4:1**

## 推荐 Component 命名

- **Component 名**:`横排徽章_左图右文`(纯结构, 不绑语义)
- **场景 INSTANCE 名**:`徽章_<具体语义>`(如 `徽章_闪电` / `徽章_奖杯` / `徽章_船舵` / `徽章_钟`)
- **内部图层名**:
  - 底板 → `底板_徽章`
  - icon → `图标_徽章`(数据驱动, 占位 RECT)
  - 文本 → `文本_徽章_数字`(dynamic)

## Variants 设计 (S11 抽完后的预期形态, 仅供理解)

> S7 阶段一你**不直接写 Variant**, 只画扁平 FRAME。 下面是 S11 抽完后通常看到的形态。

| Variant (S11 自动产物) | 来源 |
|---|---|
| 常态 | S7 所有徽章 FRAME 视觉签名一致 → S11 抽出唯一 Variant 名 `常态` |

**严禁做 Variant 的差异**(S7 阶段处理方式):
- ❌ icon 内容(闪电/奖杯/船舵)→ 占位 RECT (`图标_徽章`), 不画具体 icon
- ❌ 文本内容差异 → S7 每个 FRAME 内的 TEXT.content 直接写实际数字, S11 自动收集成 overrides
- ❌ 底板色差异 → 占位 fill, 上下文决定 (S11 视觉签名不同会切多 Variant)

## icon 上可选角标(同 pattern 扩展, 不是新 pattern)

横排徽章的 icon **可能附加一个小角标**(充值"+" / 数字 / 红点 / 感叹号 / 时间 等)。**这不构成新 pattern**, 是同 pattern 的 optional 子节点。

### icon 角标的常见位置(4-5 处, 固定)

```
       ┌─────┐
       │  右 │ ← 右上角(最常见, 数字角标 / 红点 / !)
       │  上 │
   左  │     │
   下  │ icon│
   →   │     │
       │  右 │ ← 右下角(常见, "+"充值 / 倍率 ×N)
       │  下 │
       └─────┘
          ↑
        下边框中(常见, 等级数字 / 进度小角标)
```

具体位置 + 常见内容:

| 位置 | 常见内容 | 用途举例 |
|---|---|---|
| **右上角** | 数字 / 红点 / 感叹号 | 通知红点, 新消息, 数量 |
| **右下角** | "+" / 倍率 ×N | 充值入口, 加成提示 |
| **左下角** | 数字 / 标识 | 等级 / 进度 / 标签 |
| **下边框中** | 数字 / 短文本 | 等级 / 阶段 |
| (左上角 较少见) | 数字 / icon | — |

### 识别要点

- **角标尺寸**:通常 < icon 尺寸的 50%
- **角标形状**:小圆 / 方圆角 / 椭圆,带描边或阴影
- **位置规整**:贴边或半溢出, 不在 icon 中央
- **不影响主体识别**:即便没有角标,仍是同一 pattern

### 入 JSON 怎么写 (S7 阶段一, 扁平 FRAME)

带 icon 角标的横排徽章, 整体外包 `按钮_xxx` FRAME (新 skill `07c #2/#3` 包装做法 B), 主体和角标都是扁平 FRAME:

```
按钮_金币 (FRAME 外层, 整体可点击 - 不可点击用 组_)
├── 组_徽章 / 容器_徽章 (FRAME, 内含徽章 3 图层 — 底板 + icon + 文本)
│   ├── 底板_徽章 (RECTANGLE)
│   ├── 图标_徽章 (RECTANGLE 占位)
│   └── 文本_徽章_数字 (TEXT, content="实际数字")
└── 角标_xxx (FRAME, 内含角标实际 children — 圆底 + "+" 或数字)
    位置:相对主体 icon 中心 + 偏移
    constraints:LEFT/TOP + 正坐标 (07e 角标位置铁律, 不用 RIGHT/CENTER)
```

> ⚠️ 不写 `type: INSTANCE` / `component_name` / `variant`, S11 自动抽。
> 多个金币徽章如果角标只在某些实例显示, 没显示的实例角标 FRAME 写 `visible: false` (children 跟显示实例 100% 一致)。

## 反面案例(容易跟它混)

| 看着像但不是 | 区别 |
|---|---|
| 圆形按钮 + 数字标签 | icon 在按钮内(不溢出), 数字独立 |
| icon + 数字 横排**无底板** | 此 pattern 必须有圆角胶囊底板 |
| icon **右**, 文本左 | 方向反, 是另一种 pattern |
| icon **完全嵌在**底板内 | 不溢出底板 = 是另一种 pattern("内嵌徽章") |
| 进度条 + icon | 底板内是进度条 RECT 不是纯文本 |

## 低保真 JSON 结构 (S7 阶段一, 扁平 FRAME)

```json
{
  "type": "FRAME",
  "name": "徽章_<语义>",        // 例: 徽章_金币 / 徽章_闪电
  "x": ..., "y": ...,
  "w": 240, "h": 70,            // 底板尺寸; icon 会上下溢出
  "layoutMode": "NONE",
  "children": [
    { "type": "RECTANGLE", "name": "底板_徽章",
      "x": 0, "y": 0, "w": 240, "h": 70, "corner_radius": 35,
      "constraints": { "horizontal": "SCALE", "vertical": "SCALE" } },
    { "type": "RECTANGLE", "name": "图标_徽章",
      "x": -20, "y": -15, "w": 100, "h": 100 },     // 左溢出 + 上下溢出
    { "type": "TEXT", "name": "文本_徽章_数字",
      "x": 90, "y": 18, "h": 34, "content": "实际数字",   // 直接写视频里看到的
      "font_size": 28, "textAlignHorizontal": "CENTER" }
  ]
}
```

> S11 抽完后会变成: `Component "横排徽章_左图右文"` (一个常态 Variant) + 每个 INSTANCE 通过 `overrides["文本_徽章_数字"]` 填具体数字。 这不是 S7 你要写的形态。
