用户项目里"金币堆奖励"组件的**典型 layout 是竖向带丝带**,**不是横排胶囊**。

## ⚠️ 适用范围(2026-05-12 加注)

**只适用"大型独立金币堆"**(如弹窗顶部装饰里的大金币堆 + 红丝带 + 数字)。

**不适用"行内嵌小型金币堆"**(列表行/卡片内的小金币堆奖励, 通常横排:图标左 + 数字右)。

判断标准:
- 高度 ≥ 150px 或 占总屏 5% 以上 → 大型独立 → 套规则
- 高度 < 100px 或 嵌在行/卡片内 → 行内嵌 → 通用横排 RECT, 不套规则
- 中间灰区(100~150px)→ 看上下文(独立大装饰 vs 行内附件)

## 高保真标准结构

```
┌─────────────────┐
│   [金币图标_堆]   │  ← 顶层,图标可上溢出边界
│   ═══════════   │  ← 中层底板_丝带(横向红色)
│   ═══ 6000 ═══  │  ← 数字嵌入丝带内,白色粗体
└─────────────────┘
```

视觉特征:
- 整体**纵向布局**(高 ≈ 宽 或更高)
- 顶部 1/2 是金币堆 icon(立体堆叠效果, 可超出边界)
- 中下部是红色 / 暗红丝带横向延伸
- 数字嵌入丝带内, 不是数字+底板浮在外面

## 低保真简化版

不还原立体效果, 但**保留竖向结构**:
```
- 顶层 RECT (图标_金币堆 占位)         w=parent_w, h=parent_h*0.6
- 中下 RECT (底板_丝带, 暗红, 横向)    w=parent_w, h=parent_h*0.4, y=parent_h*0.5
- TEXT     (文本_数字, 嵌丝带内)        位于丝带中心
```

**Why**:
- 2026-05-12 上午用户给了截图(金币堆+丝带+6000), 我重建成"胶囊横排+图标左+数字右" — 摆反了, 完全丢失丝带和竖向结构
- 用户特别强调"金币堆和金币堆是一组"

**How to apply**:
- 遇到含"金币堆+数字"的奖励组件 → 默认套这个竖排带丝带结构
- 不要默认套"icon 左 + 文本 右"的通用横排
- 例外:如果当前截图明显是横排, 才走通用横排(但要明确告诉用户"看到的是横排, 不套竖排模板")
