## 1. 命名白名单 — 30 个前缀枚举锁 🔴

所有 JSON 节点 `name` 前缀**必须**来自以下白名单, 违反 = 幻觉错误:

`界面_` `浮层_` `组_` `底板_` `内容区_` `内容_` `容器_` `导航_` `列表项_` `网格行_` `网格项_` `弹窗_` `按钮_` `图片_` `图标_` `背景_` `遮罩_` `文本_` `文字_` `弹性缝隙` `角标_` `徽章_` `进度_` `进度条_` `Tab_` `切换_` `请求_` `消息项_` `活动_` `底标_`

> 详细: **07a #1**
> 预制特例 (v20.7.x+ 2026-05-15): 当前仅 `钟表_指针动画` 一个预制, 详细规约见 **08a_S8_预制组件.md**

## 2. 按节点角色 → 命名前缀对照表

### 容器类 (FRAME)

| 用途 | 前缀 | 例子 |
|---|---|---|
| 屏幕 | `界面_` / `浮层_` | `界面_主菜单` / `浮层_设置` |
| 装按钮的容器 (纯分组) | `组_` / `容器_` / `弹窗_` | `组_顶部HUD` / `容器_列表滚动区` |
| 复用单元 (大 CCB) | `列表项_` / `网格行_` / `网格项_` | `列表项_排名` |
| 内容区 (AL 居中) | `内容区_` / `内容_` | `内容区_开始` |
| 弹性占位 | `弹性缝隙` | (固定 name) |
| 真按钮触控层 | `按钮_xxx` | `按钮_开始` |

⛔ 装按钮的容器**禁用 `底板_` 前缀** (引擎按 `底板_` 当 RECT 处理)。

### 按钮类 🔴 (引擎只识别 `按钮_` FRAME 为触控层)

| 角色 | 节点类型 | 命名 |
|---|---|---|
| 真按钮触控层 | FRAME | `按钮_xxx` |
| 按钮内层底板 (父是按钮 FRAME) | RECTANGLE | `底板_xxx` (父按钮 → 最浅灰) |
| 外层卡片/弹窗底板 (父非按钮) | RECTANGLE | `底板_xxx` (父非按钮 → 中深灰) |
| 组件库按钮 | (component_ref) | `圆形按钮_xxx` / `椭圆按钮_xxx` / `矩形按钮_xxx` |
| 导航按钮 | (component_ref) | `导航_项N` |

#### 按钮内层底板灰度后缀

| `按钮_` 后缀含 | 灰度 |
|---|---|
| `弹窗` / `浮层` | 最深 |
| `切换` / `卡片` | 中灰 |
| `开关` | 较浅 |
| 其余 (动作名) | 最浅 |

> 详细: **07b #5**

### 装饰类 (角标 / 徽章 / 底标)

| 用途 | 节点类型 | 前缀 |
|---|---|---|
| 角标 (右上感叹号/数字等) | FRAME / RECT | `角标_` |
| 徽章 | FRAME / RECT | `徽章_` |
| 底标 (倒计时/进度等) | FRAME / RECT | `底标_` |

⛔ 装饰**不是触控层**, 必须作为按钮 children, 不能平级。

### 进度条三层 🔴 (来自 07c #1)

| 层 | 节点类型 | 命名 |
|---|---|---|
| 外层容器 (可点) | FRAME | `按钮_xxx` (例: `按钮_活动进度`) |
| 外层容器 (不可点) | FRAME | `组_xxx` (例: `组_xxx`) |
| 包装层 (含"进度") | FRAME | `组_进度_XXX` |
| 内部底板 | RECTANGLE | `底板_XXX` (XXX 不带"进度") |
| 内部填充 | RECTANGLE | `进度条_XXX` (XXX 不带"进度") |

- ✅ `组_进度_经验` + `底板_经验` + `进度条_经验`
- ❌ `组_进度_经验` + `底板_经验进度` + `进度条_经验进度` (内部冗余)

方向后缀: 默认横向不加; `_rl` / `_bt` / `_tb`。**三层都带或都不带**, 不能只一层带。

### 占位 RECT (数据驱动)

| 内容 | 前缀 |
|---|---|
| 头像 / 玩家图片 | `图片_` |
| icon / 物品图标 | `图标_` |
| 全屏背景图 | `背景_` |
| 浮层遮罩 | `遮罩_` |

### 文字类 (TEXT)

| 用途 | 前缀 |
|---|---|
| TEXT 节点 | `文本_` / `文字_` |

### 导航 / Tab / 切换类

| 用途 | 命名 |
|---|---|
| 底部页面切换 Tab (跨屏跳转) | `导航栏_页面切换_选中` / `_未选中` |
| 屏内状态切换 Tab (不跨屏) | `导航栏_状态切换_选中` / `_未选中` |
| 通用 Tab | `Tab_xxx` |
| 切换控件 | `切换_xxx` |
| 导航按钮 (每项独立) | `导航_项N` |

> 详细: **S6 #2 导航栏双态组件** + **S9**

## 3. 屏幕级特殊命名

| 屏幕类型 | `layers[0]` 必须是 |
|---|---|
| `浮层_` 屏幕 | `遮罩_浮层背景` RECT (1080×2400) |
| `界面_` 屏幕有全屏背景图时 | `背景_xxx` RECT (1080×2400) |

⛔ 全屏背景**不能塞进**中间弹性区容器内。

## 4. 复用结构 children name 100% 一致 🔴

8 个列表行实例的内部 children name **必须严格一致**:

```text
✅ 列表项_排名1            列表项_排名2            列表项_排名3
   ├── 底板_行              ├── 底板_行              ├── 底板_行
   ├── 文本_排名            ├── 文本_排名            ├── 文本_排名
   ├── 图标_头像框          ├── 图标_头像框          ├── 图标_头像框
   └── 文本_名字            └── 文本_名字            └── 文本_名字

❌ 列表项_排名2 内部叫 `底板_排行行` (name 漂移 → S11 抽不出统一 Component)
```

**实例间差异只能是视觉属性** (`fill` / `corner_radius` / `opacity` / `visible`), **不能是命名差异**。

> 详细: **07d #1**

## 5. Variant 命名禁下划线 🔴 (v20.6+)

`components[].variants[].name` 和 `screens.layers[].variant` 引用**禁止包含 `_`**:

- ✅ `常态` / `已完成` / `当前用户` / `带徽章` / `有头衔无道具`
- ❌ `有头衔_无道具` / `状态_选中` (Figma `combineAsVariants` 会归并/吞掉)

> 详细: **S11**

## 6. 同屏 name 唯一性

**同一屏幕内没有重名节点** — 否则 `flow.from_node` 引用混乱, 引擎找不到目标。

> 详细: **07a #7**

## 7. 禁用命名清单 (老版本残留)

| ❌ 老命名 | 来源 | 替代 |
|---|---|---|
| `切图_底板_xxx` | v18 | `底板_xxx` |
| `底板_xxx 形状` 后缀 | v19 | `底板_xxx` (不加形状后缀) |
| `底板_xxx FRAME` 当按钮 | v19 | `按钮_xxx` FRAME |
| 装按钮的容器用 `底板_` 前缀 | — | `组_` / `容器_` |
| 组件库内部子节点用纯 `按钮_xxx` | — | `活动按钮_xxx` / `按钮组_xxx` / `按钮_底板` |
| `按钮_xxx` FRAME 内嵌 `按钮_` 前缀 FRAME | — | **嵌套禁止** (引擎冲突) |

> 详细: **07a #7** + **07b #6**

## 8. `component_ref` 节点 — 两个字段区分 🔴

`component_ref` 节点有**两个不同的字符串字段**, 易混用:

| 字段 | 含义 | 取值来源 | 例子 |
|---|---|---|---|
| `component_ref` | **组件库条目名** (引用哪个组件) | 旧组件库 JSON 的 key (固定) | `"椭圆按钮_活动"` |
| `name` | **该实例在屏幕里的语义命名** | 视频里这个实例的实际语义 (每实例不同) | `"活动_紫罐"` / `"活动_花朵"` |

```json
[
  { "component_ref": "椭圆按钮_活动", "name": "活动_紫罐" },
  { "component_ref": "椭圆按钮_活动", "name": "活动_花朵" },
  { "component_ref": "椭圆按钮_活动", "name": "活动_盾牌" }
]
```

⛔ 禁止: `name` 写成 `component_ref` 名 (4 实例 name 全一样); `component_ref` 写成实例语义名 (组件库找不到)。

> 详细: **S8 #0**

## 9. flow 字段命名 🔴

| 字段 | 含义 | 取值 |
|---|---|---|
| `from` | **源屏 name** (源屏在 screens[] 里) | `"界面_主菜单"` |
| `from_node` | **触发节点 name** (在源屏 layers 里) | `"按钮_开始"` / `"导航_项3"` |
| `to` | 目标屏 name (浮层 CLOSE 用空字符串) | `"界面_关卡选择"` / `""` |

⛔ **常见错误**: 把 `from` 写成触发节点 — `"from": "按钮_开始"` 是错的。
✅ 正确: `"from": "界面_主菜单", "from_node": "按钮_开始"`

> 详细: **S9 #4**
