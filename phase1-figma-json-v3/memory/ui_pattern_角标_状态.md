# 角标_状态 pattern

主体(icon / 容器 / 徽章)**边缘**附加的小状态标识。**贴在主体边角或半溢出**, 不会出现在主体中心。

## 5 维特征

| 维度 | 规律 |
|---|---|
| 形状 | 圆 / 方圆角 / 不规则(锁、铃铛等) |
| 构成 | **1 层(无底板)** 或 **2 层(底板+内容)** |
| 位置 | 主体边缘 4 处之一(见下"位置图")|
| 量级 | 角标 w/h < 主体 w/h **× 50%**;细分:状态角标(数字/对勾/!) **15%~25%**;按钮型角标(+/可点击) **25%~40%** |
| 底板 | **二分:有/无**(决定 Variant) |

## 位置图(主体边缘 4-5 处)

```
       ┌─────────┐
       │右上(*)  │ ← 数字 / 红点 / 感叹号(image 4)
       │         │
   左  │         │  右
   下  │  主体   │  下(*) ← + / 倍率 / 对勾 / 锁(images 1, 2, 3, 5)
   →   │         │
       │右下边框 │
       │居中(*)  │
       │下边框   │
       └─────────┘
            ↓
        下方溢出
```

`(*)` = 本次观察到的高频位置

## 带底板 vs 不带底板(用户核心 teaching)

### A. **带底板角标**(更常见)

底板可以是:
- **圆底**(最常见, 红/绿/白圆)
  - 红圆 + 白数字(images 3, 4): `角标_数字`
  - 绿圆 + 白对勾(image 5): `角标_对勾`
  - 红圆 + 白"+":`角标_补充按钮_+`(之前的金币 1102 那张)
- **方圆角底**(矩形+大圆角)
  - 白圆角方 + 绿对勾(image 2): `角标_对勾_方底`

### B. **不带底板角标**(较少)

单一图形, **没有底板背景**, 通常是**装饰类**:
- 灰色锁(image 1): `角标_锁`
- 铃铛 / 装饰 icon

## Variant 设计 (S11 抽完后的预期形态)

> S7 阶段一你**不直接写 Variant**, 只画扁平 FRAME 用 `visible: true/false`。 S11 自动抽 Variant。

| Variant (S11 自动产物) | S7 阶段你怎么写 |
|---|---|
| 常态 (角标显示) | 角标 FRAME `visible: true` + children 完整 (圆底板 + 数字/对勾...) |
| 空 (角标不显示) | 角标 FRAME `visible: false` + children **跟显示实例 100% 一致** (规则 11.5) |

S11 自动用 `_filter_invisible` 把 visible:false 节点的 layers 过滤成空 → 切出"空 Variant"。

## ⚠️ Component 命名(2026-05-12 用户教学**修正**)

**之前错的方向**:把每种内容(锁/对勾/数字/红点/!/+/倍率)做成多个独立 Component → ❌

**正确方向**(新 skill 07d 子 CCB 显隐铁律 + 用户教学):
- 如果跨多个实例**在同一位置出现, 内容不同** → S7 每个实例画扁平 FRAME (children name 100% 一致, 视觉差异 / visible 不同), S11 自动抽**同一 Component 多 Variants**(含空 Variant)
- 不是按"内容"分独立 Component, 而是按"**位置 + 角色**"分

### 例:排行榜行右上角"状态角标"位置 — S7 阶段一怎么写

```
排行榜 10 行, 每行右上角都有同一"角标"位置, 但内容随状态变:

S7 阶段每行画完整扁平 FRAME (children name 100% 一致):
  行 1: 角标_状态 FRAME visible:true,  children=[底板_圆角标(灰), 图标_锁]
  行 2: 角标_状态 FRAME visible:true,  children=[底板_圆角标(绿), 图标_对勾]
  行 3: 角标_状态 FRAME visible:true,  children=[底板_圆角标(红), 文本_数字(content="5")]
  行 4: 角标_状态 FRAME visible:false, children=[底板_圆角标, 图标_锁]      ← 跟行 1 children 一致, 只是隐藏
  ...

S11 自动抽:
→ 一个 `角标_状态` Component
→ Variants = [常态(锁/对勾/数字 视觉签名不同 → 多 Variant), 空(从 visible:false 切出)]
→ 视频里读到几种, S11 自动装几种
```

### S11 抽完的 Variants 形态参考表 (不是 S7 你要写的)

| Variant (S11 产物) | 来源 — S7 阶段每个角标 FRAME 怎么画 |
|---|---|
| 锁 | 灰圆底板 + 图标_锁, visible:true |
| 对勾 | 绿圆底板 + 图标_对勾, visible:true |
| 数字 | 红圆底板 + 文本_数字 (content="5" 等实际值), visible:true |
| 红点 | 单一红圆 RECT, visible:true |
| 感叹号 | 红圆底板 + 图标_感叹号, visible:true |
| 补充按钮(+)| 绿圆底板 + 图标_+, visible:true |
| 倍率 | 椭圆/矩形底板 + 文本_倍率 (content="×2" 等), visible:true |
| **空** | **任意上述 children 不变, 但 FRAME `visible: false`** |

> 关键: S7 阶段 children 必须跟"有显示"的实例 100% 一致, 否则 S11 抽不出统一 Component。

### 何时跟之前的"按内容分独立 Component"不同

- 同一界面里 **N 个角标在不同主体上**(每行 1 个角标), 但**内容不同** → S7 画 N 个独立扁平 FRAME (children name 一致), S11 自动抽同 Component 多 Variants
- 同一界面里 **1 个角标独立显示**(整界面只有 1 个红点)→ S11 可能不会抽 Component (只有 1 个实例, 达不到 min_instances), 直接保留扁平 FRAME 即可

## 角标如何挂到主体上 (S7 阶段一, 扁平 FRAME)

按新 skill `07c #2/#3` 「做法 B」 — 主体和角标都是扁平 FRAME:

```
按钮_<语义>(FRAME 外层 - 整体可点击; 不可点击用 组_xxx / 容器_xxx)
├── 组_<主体> / 容器_<主体> (FRAME, 内含主体 children — 底板 + icon + 文本 等)
└── 角标_<位置/角色> (FRAME, 内含角标 children — 圆底板 + 数字/对勾...)
    位置:相对主体, x/y 按 4 处位置 之一
    constraints: **LEFT/TOP + 正坐标** (新 skill 07e 角标位置铁律, 不用 RIGHT/CENTER — Figma 实例会飞出)
```

> ⚠️ S7 阶段:
> - 不写 `type: INSTANCE` / `component_name` / `variant`
> - 角标在某些主体上不显示 → 角标 FRAME 写 `visible: false`, children 跟显示的角标 100% 一致 (规则 11.5)
> - S11 自动抽 Component + 切 Variant

## 识别信号(看截图判断时,≥3 条命中即匹配)

- [ ] 元素在主体**边缘**(不在中心)
- [ ] 尺寸明显**小于主体**(< 50%)
- [ ] 形状**规整**(圆/方圆角/特定图形)
- [ ] 内容是**单一标识**(1-3 字符 / 1 小图标)
- [ ] 通常带**描边**(白边/深边, 与主体形成视觉对比)

## 反面案例

| 看着像角标但不是 | 区别 |
|---|---|
| 主体内部小装饰 | 在中心区, 不是边缘附加 |
| 主体的子图层(如宝箱锁) | 是主体结构的一部分, 不溢出/不可拆 |
| 大尺寸装饰 | 尺寸 > 50% 主体, 已经是"次要主体"不是角标 |
