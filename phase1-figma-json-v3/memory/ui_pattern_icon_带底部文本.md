# icon 带底部文本 pattern

主体 icon **正下方挂载**一个文本/标签元素。底部文本的形态有多种, 但跟 narrow `底标_倒计时` 区分(那个有左钟表+右底板特定结构)。

## ⚠️ 跟 narrow "底标" 区分

| 概念 | 范围 | 例 |
|---|---|---|
| **底标**(narrow) | 特指 **左侧钟表 icon + 右侧底板+文本** 形态(=横排徽章钟表变体), **且位置在浮层/卡片底部正中央**| `底标_倒计时`(钟表+"2d 22h")|
| **icon 带底部文本**(broader, 本 pattern)| icon 下方挂任意形态文本 | 本 pattern 的 4 个子形态 |

### narrow 底标 严格定义(2026-05-12 用户教学)

- **位置**:浮层 / 卡片 / 主体的**底部正中央**(不是任意位置, 不是右下/左下)
- **内容形态**:**倒计时**(钟表 icon + 时间文本)
- **视觉**:左钟表 + 右底板+文本(=横排徽章 钟表变体)
- **典型场景**:浮层活动入口的最底部、复合按钮(如 image"Level 253" 下挂)
- 如果不满足这 3 个特征 → 不是 narrow 底标, 是 broader `icon 带底部文本`

## 5 维特征

| 维度 | 规律 |
|---|---|
| 形状 | 主体 icon(任意形状)+ 下方挂载文本元素 |
| 构成 | 主体 icon + 底部文本元素(1-3 层)|
| 位置 | 文本**正下方**(中心对齐)或**下方居中**(可略溢出主体边)|
| 量级 | 文本元素 h ≈ 主体 h × 25%~40%(不能跟主体一样大)|
| 底板 | 文本元素可带各种底板(丝带/方圆角/胶囊/无底板)|

## 4 个子形态(按底部文本的底板形态分)

### A. **丝带飘带**(banner ribbon)

特征:
- 底部文本挂在**绿色 / 红色 / 米黄等丝带飘带**上
- 丝带带"翻折"装饰(两端有 V 字形或斜切口, 看起来像旗帜)
- 文本嵌在丝带内, 居中

例:
- 蓝卡包 + 绿色丝带飘带"4 Cards"
- TNT 物品 + 绿色丝带飘带"∞ 1h"
- 王冠卡 + 红色丝带+金币 "500"
- 蛋糕 icon + 绿色丝带"x1"

推荐 Component 名(S11 抽完之后):`底标_丝带`(或更具体 `底标_丝带_绿/红/...`)
S11 抽完 Variants (参考): [常态, 空 (从 S7 visible:false 切出)]

### B. **圆角矩形数字标签**(简单底+数字)

特征:
- 底部文本挂在**圆角矩形底板**上(无丝带装饰, 无圆按钮风格)
- 通常深色底+浅色数字
- 多见于里程碑阈值标签

例:
- 进度条多节点 "400" "800" "1200"(棕色圆角矩形 + 米黄字)
- 等级要求数字

推荐 Component 名(S11 抽完之后):`标签_数字底板`
S11 抽完 Variants (参考): [常态, 空 (从 S7 visible:false 切出)]

### C. **按钮型**(可点击)

特征:
- 底部文本是**按钮**形态(矩形+圆角+亮色, 中央纯文本)
- 通常绿/橙/红 鲜艳色
- 文本是动作类("OPEN" / "PLAY" / "CLAIM" / "GO")

例:
- 进度条多节点 "OPEN" 绿色按钮
- "PLAY" / "CLAIM" 等动作按钮

推荐 Component 名(S11 抽完之后):`按钮_纯文本`(单独抽 pattern)
S11 抽完 Variants (参考): [常态, (若有禁用态)禁用, 空 (从 S7 visible:false 切出)]

### D. **纯文本**(无底板)

特征:
- 底部文本**无任何底板背景**
- 通常只有简单符号或一两个字符
- 多见于状态标识

例:
- 进度条多节点 ✓(绿色对勾, 无底板)
- 红 X / 数字直接显示

推荐 Component 名:`角标_对勾` 或 `图标_状态_X`(复用 `角标_状态` pattern 中的"无底板"子类)

## 识别信号(≥3 命中即匹配)

- [ ] 主体是 icon(单独 icon 或物品)
- [ ] icon **正下方**挂一个**独立元素**(不是角标 4 角位置)
- [ ] 下方元素**整体宽度 ≤ 主体宽度 × 1.5**(差不多窄)
- [ ] 下方元素带**文本内容**(可能是数字 / 标签 / 状态 / 按钮文字)
- [ ] **不是 narrow 底标**(没有左钟表 icon)

## 区分相邻 pattern

| 看着像但不是 | 区别 |
|---|---|
| **narrow 底标**(底标_倒计时)| 那个有"左钟表 icon + 右底板+文本"结构, 不是单纯下挂文本 |
| **角标_状态** | 角标在主体 4 角(右上/右下/左下/下边框中, 部分位置和"下方"接近); 而本 pattern 是**正下方挂载**, 不溢出 4 角 |
| **横排徽章** | 是横向 layout(icon 左 + 数字右), 不是上下结构 |
| **进度条** | 主体是长条 RECT, 不是 icon |

## Component 设计 (S7 阶段一, 扁平 FRAME)

### 上下结构: 整体 FRAME 容器 + 主体 / 底部文本 都是扁平 FRAME

```
组_<语义>_带底部文本 (FRAME 外层容器, 1 个; 整体可点击改成 按钮_<语义>)
├── 主体 (FRAME, 内含 icon children — 占位 RECT 或 实际 icon 节点)
└── 底部文本 (FRAME, 内含子形态 children — 丝带/数字底板/按钮/纯文本)
    位置: 主体正下方, x 居中, y = 主体 h + 间距(通常 0~20 px)
```

对应新 skill `07c #2/#3` "做法 B" 包装。 本 pattern 主体+底部文本通常**仅展示, 不可点击**, 用 `组_xxx` 即可(不是按钮)。

例外: 若 D 子形态是"按钮文本"(OPEN 等), 整体可能可点击 → 用 `按钮_xxx` 包装。

> ⚠️ S7 阶段不写 `type: INSTANCE`, 全是扁平 FRAME。 底部文本在某些实例不显示 → 该 FRAME `visible: false` (children 跟显示实例 100% 一致)。
