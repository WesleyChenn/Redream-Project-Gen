## 9 层自检清单

### 【第 1 层】 骨架完整性

```
✅/❌ [仅录屏] S1 抽帧完成 (3 fps 全帧抽完, 不跳帧)
✅/❌ [所有输入] S2 识别页面内容完成 (含相似元素双重核查)
✅/❌ [仅录屏] S4 识别交互完成 (触摸点像素扫描 + 滚动区识别 + 帧间按钮缩放推点击)
✅/❌ [仅录屏] S5 提取 flow 完成 (帧差分屏幕清单 + 转场回溯 + 翻页类型识别)
✅/❌ S3 骨架表 A (大区) + 表 B (AL 对齐) + 表 C (组团结构) 已输出
✅/❌ 骨架无重叠, 所有大区 h 加总 = 2400 (算术闭环)
✅/❌ 贴底区域从 y=2400 往上叠加, 未从上往下估算
✅/❌ 所有 h/w 已量测后 × scale (非估算值)
✅/❌ S3 组团化全覆盖 (S2 数过的相似 N 项都包进空 FRAME)
```

**失败回退**: 回对应 S 步骤 (S1/S2/S3/S4/S5) 重做。

> 注: "子容器 h > 父容器 h" 是 HUG 内容多自然产生的结果, 不作为自检铁律。判断滚动区基于 S4 表 D。

**Figma 端 3 种错误对照** (来自 旧 02 末):

| 现象 | 原因 | 修法 |
|---|---|---|
| 整屏跟着滚, 顶部固定区也上移 | clip_content 写成 clipsContent (驼峰错误) | 改 clip_content |

| 滚动区一直不动 | 父容器 overflow 缺失 / NONE | 加 overflow: VERTICAL |

## 违规处理流程

每条 ❌ 应按以下三步:

1. **标注问题节点** (在 scene.json 里的具体路径 + 错在哪个字段 / 哪条规则)
2. **指向回退步骤** (上表已列, 例如 第 1 层 → S3, 第 7 层 → S5/S9)
3. **修后重新跑 S10 自检** 直到全部 ✅

---

## 违规信号 (S10 自身)

| 出现的行为 | 说明 |
|---|---|
| S10 阶段直接修 JSON 字段 | 越界, 应回对应 S 步骤修 |
| 跳过某层自检 (例: 不查命名合规) | 违反"逐层必查" |
| 第 N 层有 ❌ 但标"可以容忍" | 违反"任一 ❌ 必须修" |
| 抢跑做 v20.6 schema 验证 (Variant 命名 / INSTANCE 同步 / 嵌套化) | 抢跑到 S11 末尾 |
